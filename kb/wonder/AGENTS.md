# 孩子的奇妙视界（kb/wonder）

这个库服务“孩子提问、老爸承接”的亲子共学场景：回答孩子关于外部世界和自我的“为什么”问题，同一个问题讲给孩子和老爸两层听，按年龄控制深度，并把高价值回答沉淀成笔记。本库卡片很少，核心是一套回答方法（见 `skills/`）。事实来源优先用本仓库各知识库的 Markdown 卡片，其次是模型已有知识，需要时联网核查；不伪造来源、页码、实验结论。共通规范见 `../README.md`。

## 目录与卡片

| 目录 | doc_type | 文件名模式 | 用途 |
|---|---|---|---|
| `notes/` | `topic_note` | `topic-0001-short-slug.md`（id `topic-0001`） | 主题笔记：一个核心问题的孩子层、老爸层、关键机制、活动、追问、易错点、来源与边界 |
| `notes/` | `answer_script` | `script-0001-short-slug.md`（id `script-0001`） | 回答脚本：30 秒版、3 分钟版、老爸接话、互动动作、配图说明、旁白 |
| `skills/` | — | `wonder-*.md` | 回答方法（DSH skill），不是卡片 |
| `_templates/` | — | `*_template.md` | 写卡模板，不是答案来源 |

`notes/README.md` 是目录说明，不是卡片。两种卡片各自编号。

## 回答时

- 回答孩子的好奇问题：加载 skill `wonder-answer`（流程、查找顺序、联网判断、话术）和 `wonder-age-stages`（各年龄段讲法），照做。
- 查找优先级：
  1. 常见“为什么”：本库 `notes/` → `kb_search` 其他库（自然科学查 `science`，AI 和科技查 `ai`，情绪和自我查 `psychology`）→ 模型已有知识；不为显得专业而联网。
  2. 新近事件、精确数据、具体产品/地点/新术语、用户要来源或最新信息：先查库，再 `web_search` 找页面、`web_fetch` 读正文核对，然后组织答案。
- 回答原则：
  - 默认中文，答案优先，不先铺背景。
  - 优先用 `reviewed` / `published` 卡片；用了 `draft` 要说明。
  - 默认两层：给孩子怎么说（短句、具象、可观察、少术语），给爸爸怎么接（机制、接话、追问、动作）。
  - 没有现成卡片时，明确标注“基于现有知识库模式整理的草案”；联网补充的内容标明是联网补充。
  - 医疗、心理、安全风险问题不轻描淡写，提示必要时求助专业人士。
  - 模型没有图像、音频能力时只输出画面说明和旁白脚本，不假装已生成成品。
- 回答结构（标准模式）：给孩子怎么说 → 给爸爸怎么接 → 一起观察或做个小实验 → 可以继续问孩子什么 → 依据与边界（需要时）。快速、深入模式的增减见 `wonder-answer`。
- 澄清策略：没给年龄时，能合理推断就先写明默认年龄假设直接回答；年龄会显著改变深度时先补问。补问顺序：年龄 → 只讲给孩子还是也要给爸爸解释 → 快速回答还是带活动和追问。

## 设计新内容

- 先用 `kb_search` 在本库和其他库找相近卡片，能复用其机制、实验或话术就复用，并在 `related:` 里关联。
- 安全和年龄适配优先：活动必须在家能安全做；解释深度服从年龄，不服从模型能说多复杂。
- 能动手理解的问题尽量配一个观察、对比、小实验或身体动作。
- 问题允许时把外部世界连回孩子自己（现象 → 身体感受 → 情绪 → 行动），但不生硬上价值。
- 记录容易讲偏的地方：常见误解、过度简化、错误比喻。

## 写回

- 适合写回：高频问题；多个年龄段都值得保留；回答结构已稳定；用户明确说“把这个沉淀下来”。一次性闲聊和即兴草稿不写。
- 写回顺序：先写 `topic_note`（默认优先）；需要成品讲稿、配图或旁白时再写对应 `answer_script`，并与主题笔记互相 `related:`。
- 新卡一律 `status: draft`；写之前调用 `kb_schema` 拿模板、下一个 id 和建议路径；写完调用 `kb_check`。
- 一个文件只处理一个核心问题；必须写明适用年龄段、`world_or_self`、孩子层、老爸层、活动建议和来源方式。
- 依赖联网信息时：`source_mode` 写清来源方式，`web_refs` 记录实际读过的页面，`refresh_needed: true`，并在“来源与边界”写明以后要刷新核查的点。
- 跨库关联写在 `related:`，格式 `库id/卡片id`（如 `science/experiment-0074`）；同库只写 id。
- 不改其他库的卡片。

## 提升到 reviewed 前

- 一个文件一个核心问题，“核心问题”一句话说清。
- 年龄段已标注，孩子层句长和因果层数符合该年龄段（见 `wonder-age-stages`）。
- 孩子层与老爸层分开；老爸层有机制、接话、追问、动作。
- 至少一个安全、马上能做的观察或活动。
- 写了容易讲偏的地方。
- 联网事实已用 `web_fetch` 读原文核对，来源可追溯，没有伪造。
- 涉及医疗、心理、安全风险的内容没有轻描淡写。
- `kb_check` 通过。
