# 核心观点

- 家庭氛围是教育的基础。家庭氛围越好，孩子的发展越有可能令人满意。
- 遵守内部的权利和义务：每个家庭成员的职能都应受到尊重。任何成员的职能获得的认可越少，他就越无法充分履行这一职能。
- 一致性是训练孩子的关键原则。只有相似的经历反复出现，孩子才能学到东西。明确的规则必须在任何时候、任何情况下都统一适用。
- 果断：态度是否坚定，不是靠嗓门大小衡量的。低声而坚定的命令比大喊大叫更有效。声音大通常表明内心犹豫。
- 自然后果是训练孩子最有效的方法之一。后果不是惩罚，而是让孩子体验行为与生活结果之间的自然联系。对孩子来说，后果是可以接受的，惩罚充其量只是可以忍受。
