# 核心观点

- 教育成功的核心是培养孩子足够的社会兴趣。只有孩子对他人、家庭和社区有归属感，才可能发展出健康的自信和责任感。
- 训练方法应以“适应”为目标，“平和”为方式，“鼓励”为实质。避免与孩子发生斗争，不要把教育变成权力对抗。
- 鼓励是儿童成长的基本动力：它像水一样支持孩子的自信、力量、社会兴趣和自力更生。
- 让孩子尊重秩序、接受规则、理解自然后果，胜过单纯的惩罚。后果不是惩罚，而是让孩子体验行为与生活结果之间的联系。
- 规则必须一致、明确且不打折扣。孩子通过重复的相似经历学习规则；任何例外都会削弱规则的效力。
- 态度坚定不在于声音大小，而在于内心决心与表达的感染力。低声而坚定比大喊大叫更容易让孩子感到稳定。
- 成人的情绪（忧虑、烦躁、愤怒）会破坏教育效果。若自己可能失去自控力，应先离开、冷静，再以理性方式处理问题。
- 当孩子看似无视你的要求时，通常是他已预期你的反应。这个时候，先弄清他想看到什么，再用出其不意的方式重新建立互动。

## 可拆出的阶段卡或支持卡

- 支持卡：从权力斗争转向合作教育的具体步骤。
- 支持卡：如何把“自然后果”变成常态而非惩罚式管教。
- 支持卡：用鼓励代替说教，在孩子面前保持平静和一致性。

## 家长会怎么问

- 我该怎么让孩子听话而不是跟我斗？
- 为什么我规矩多孩子反而更不服从？
- 孩子一次又一次不做家务，我要不要惩罚他？
- 我总是忍不住生气，这样对教育有帮助吗？
