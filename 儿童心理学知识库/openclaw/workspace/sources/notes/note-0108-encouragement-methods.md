# 核心观点

- 鼓励是教育中产生一切积极影响的手段。孩子需要鼓励，就像植物生长需要水。
- 称赞与鼓励不同。称赞往往关注结果和天赋，鼓励关注过程和努力。有效的鼓励培养内在动力。
- 引导和指示：当孩子遇到困难时，提供具体的引导比说教更有效。帮助孩子找到解决问题的方法。
- 相互信任：通过坦承自己的不完美，你可以和孩子建立更亲密的关系。孩子也有感情，和成年人的感情没有什么区别。
- 用"可以"代替"必须"：改变说话方式，从命令变为邀请。比如"你可以试试这样做"而不是"你必须这样做"。
- 努力：鼓励孩子的努力，而不仅仅是结果。让孩子相信通过努力可以进步。
- 揭示：帮助孩子认识自己行为背后的真实意图，比说教更有效。
- 儿童群体中的孩子：孩子很早就需要同龄伙伴。只有和其他孩子在一起，孩子才能感觉自己是平等者中平等的一员。
