# 核心观点

- 观察和反思：如果不认真思考，父母将永远无法充分利用对指导儿童发展至关重要的情境。缺乏深思熟虑是不可能养育好孩子的。
- 克制：想要影响孩子，最根本的原则之一是尽可能克制。多观察，尽量少干涉孩子的行为。最好的教育方法是尽快让方法本身变得多余。
- 灵活性：如果你在行动前观察、思考，就不会采用任何死板的方法。孩子事先就知道你对某种行为会做出怎样的反应，从而调整自己来适应它。
- 激发兴趣：当孩子似乎完全无视你时，他实际上仍期待你的反应。通过反其道而行之，你让孩子措手不及，迫使他重新考虑自己的态度。
- 赢得孩子的信任：单靠爱和温柔是达不到这个目的的。孩子是否听话，取决于他是否相信你的公正和坚定，以及你的善意和可靠度。
- 缓解局势：无论孩子有多生气、固执或叛逆，你都应该保持冷静、友好。一句温暖的话语，往往能创造奇迹。
- 撤离：当你感觉要失控时，暂时离开是最好的选择。冷静后再回来处理问题。
