# 核心观点

- 理解孩子就是理解人性。只有通过深入了解个性的发展，才能对个性有清晰、理性的认识。
- 孩子在六岁之前会形成潜在的行为计划，这个阶段改变相对容易；六岁以后，改变会困难得多。
- 童年最大的痛苦不是身体的疾病，而是被群体排斥、没有归属感、被漠视和忽视的感觉。
- 自卑感是孩子发展社会兴趣的主要障碍。自卑的孩子不再对社会参与感兴趣，而转向追求优越。
- 孩子的勇气是与生俱来的，只要不被错误的训练破坏，就是非凡的。勇气是成功人生的先决条件。
- 一个人的自我评价不取决于实际能力，而取决于对自己在群体中相对地位的主观解释。

## 家长会怎么问

- 为什么孩子总觉得自己不如别人？

- 怎么判断孩子是否有自卑心理？
