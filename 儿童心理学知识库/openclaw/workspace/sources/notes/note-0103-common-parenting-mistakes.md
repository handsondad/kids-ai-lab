# 核心观点

- 维持正常人际关系的基本原则是相互尊重。教育中所有的错误都是违反合作这一基本原则的后果。
- 不尊重孩子的父母会羞辱或束缚他，打击或过度保护他。如果父母允许孩子支使他们，纵容孩子，使自己成为孩子的仆人，就是无视自己的尊严。
- 吓唬孩子：焦虑导致父母夸大生活中的危险。过度谨慎导致的结果和考虑不周是一样的，高估危险相当于增加危险。作为预防危险的手段，勇敢胜过焦虑。
- 过度监督：忧虑的父母从不让孩子独立行动，孩子的一举一动都是规定好的。对自己没有信心的父母，同样怀疑孩子的能力。
- 过度交谈：大多数父母不行动，甚至不思考，只是说说而已。语言可以是交流的手段，也可以是战争的工具。
- 只有给孩子留下深刻的印象，教育的影响才具有持久的价值。几次令人难忘的经历会对孩子的性格形成产生深远的影响。

## 家长会怎么问

- 我是不是保护过度了？
- 孩子说我太唠叨，怎么办？
- 怎么判断我是不是管得太多？
- 孩子总说"我知道了"，是不是我话说太多了？
