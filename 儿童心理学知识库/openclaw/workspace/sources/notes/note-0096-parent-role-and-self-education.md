# 核心观点

- 父母必须承担自我教育的责任，学会认识和理解自己。父母必须先克服对自己的不信任，才能以平和、自信的态度对待孩子。
- 孩子的行为是对父母行为的真实回应。教育是父母和孩子之间不停互动的过程，是双方活动的产物。
- 孩子比成年人更善于适应他所接触的人。他的性格尚未定型，更善于观察、更敏感、更灵活。
- 父亲的影响反映在孩子对工作和实际成就的态度上。父亲是最能激励孩子有所作为的人，但也容易让孩子泄气。
- 父母之间的分歧不要让孩子察觉。父母一方只能通过坦诚的讨论和协商来修正另一方的策略。
- 身教大于言教。当你意识到遵守秩序和规则对孩子的发展至关重要时，你必须让自己遵从同样的规则。

- 我总是控制不住情绪，怎么办？
- 孩子不听我的话，是不是我哪里做错了？

- 我和配偶教育理念不一致，经常吵架，怎么办？
