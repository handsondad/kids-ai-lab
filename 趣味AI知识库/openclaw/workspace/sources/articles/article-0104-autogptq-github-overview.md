# AutoGPTQ: User-Friendly GPTQ Quantization Toolkit

## Introduction

AutoGPTQ is an easy-to-use package for GPTQ-based weight-only quantization of LLMs. It provides APIs for quantization, loading quantized checkpoints, and inference.

## Key Features

- GPTQ-based 4-bit quantization workflows.
- Support for multiple kernels and hardware paths.
- Integration with transformers and related ecosystem tools.
- Quick-tour examples for quantization and generation.
- Benchmarks and model support matrix for practical selection.

## Getting Started

Install from pip or source, then use AutoGPTQ model classes for quantization and inference workflows.
