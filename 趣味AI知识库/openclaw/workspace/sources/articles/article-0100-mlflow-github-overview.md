# MLflow: Open Source AI Engineering Platform

## Introduction

MLflow is an open-source AI engineering platform for agents, LLM applications, and traditional ML models. It supports debugging, tracing, evaluation, monitoring, and deployment workflows.

## Key Features

- Experiment tracking and model lifecycle management.
- LLM and agent tracing with observability capabilities.
- Evaluation and quality monitoring pipelines.
- Prompt management and optimization workflows.
- Broad integrations across frameworks, model providers, and deployment targets.

## Getting Started

Start an MLflow server, set tracking URI in code, and enable autologging/instrumentation. Teams can then inspect runs, traces, metrics, and artifacts in the MLflow UI.

## Notes

MLflow is suitable for teams standardizing end-to-end AI engineering practices across both classical ML and GenAI systems.
