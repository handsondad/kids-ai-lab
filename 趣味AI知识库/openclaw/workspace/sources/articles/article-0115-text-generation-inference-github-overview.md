# huggingface/text-generation-inference

## What This Source Is

This source is the Text Generation Inference (TGI) repository for serving large language models with production-oriented APIs and performance features.

## Key Points Extracted

- TGI provides high-throughput LLM serving with token streaming, continuous batching, and tensor parallelism.
- It exposes OpenAI-compatible chat/completions endpoints plus REST API docs and deployment examples.
- The project includes quantization paths and distributed tracing/metrics support for production operations.
- Hardware support spans multiple accelerator ecosystems via dedicated images and build/runtime options.
- Repository notices indicate archived/read-only status and maintenance-mode guidance with migration suggestions.

## Why It Matters

TGI remains a key reference architecture for production LLM serving patterns, even as teams evaluate active successors.
