# ClearML: End-to-End MLOps and LLMOps Suite

## Introduction

ClearML is an open-source platform for ML and GenAI workflows, covering experiment management, orchestration, data management, and model serving.

## Key Features

- Experiment tracking with environment, code, metrics, artifacts, and logs.
- Orchestration and remote execution via ClearML Agent.
- Data versioning and management over object storage backends.
- Pipeline automation, HPO workflows, and operational dashboards.
- Support for self-hosted and hosted deployment modes.

## Getting Started

Install the SDK with pip, run clearml-init to connect credentials, and instrument code with Task.init for automatic tracking.

## Notes

ClearML is suitable for teams building reproducible and automated ML or LLM application lifecycles.
