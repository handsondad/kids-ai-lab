# 文章定位

Semantic Kernel 是面向企业场景的模型无关 AI 编排 SDK，支持多语言与多代理协作，强调插件扩展、流程治理和可运维落地。

## 核心观点

- 企业级 Agent 系统需要模型无关与基础设施可替换能力。
- 单 Agent 到多 Agent 的协作应统一在同一编排框架内。
- 插件与流程框架让业务能力可组合并可审计。
- 多语言 SDK 有助于跨技术栈团队统一开发范式。

## 值得保留的方法或框架

- Model-agnostic orchestration: 统一抽象不同模型与服务提供商。
- Plugin-first extensibility: 通过函数、OpenAPI、MCP 扩展能力。
- Process framework: 用结构化流程表达复杂业务任务。

## 局限与偏见

- 功能较全导致学习曲线较陡，初期建模成本不低。
- 生产收益依赖团队治理和监控体系配套。
- 跨语言一致性需要额外规范与工程约束。
