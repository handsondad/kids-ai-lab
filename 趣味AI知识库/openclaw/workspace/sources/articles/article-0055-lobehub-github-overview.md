# 文章定位

LobeHub 是以 Agent 为工作单元的人机协作空间，强调多 Agent 协同、可扩展插件与自托管能力，适合作为面向团队的 AI 交互与协作前端层。

## 核心观点

- 把 Agent 从单次对话工具提升为持续协作对象。
- 支持多模型与插件生态，强化可扩展性与可组合性。
- 提供自托管与本地开发路径，兼顾个人与团队部署。
- 引入个人记忆与协作空间，强调长期上下文积累。

## 值得保留的方法或框架

- Agent as unit of work: 用任务单元而非单轮对话组织交互。
- 多人多 Agent 协作空间: 支持并行分工与结果汇聚。
- 前端工作台 + 插件扩展: 快速试验多种能力组合。

## 局限与偏见

- 平台功能较多，初次配置与治理策略需要时间沉淀。
- 作为应用层工作台，底层推理与检索能力仍依赖后端栈。
- 插件生态在快速迭代期，稳定性与兼容性需持续评估。
