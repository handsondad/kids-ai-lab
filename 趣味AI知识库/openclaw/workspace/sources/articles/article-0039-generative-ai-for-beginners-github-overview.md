# 文章定位

Generative AI for Beginners 是面向初学者的 21 课课程仓库，结合概念课与构建课，覆盖提示工程、RAG、安全、Agent、微调等主线。

## 核心观点

- 课程结构完整，支持从基础认知到应用构建逐步推进。
- 每课带代码与扩展学习链接，适合做系统性自学路径。
- 支持多语言内容与多模型接入路径，全球可访问性较高。
- 强调负责任 AI、应用生命周期与安全设计，不只讲调用。

## 值得保留的方法或框架

- Learn/Build 双轨课型: 先理解再落地。
- 课程化里程碑: 适合拆成阶段目标管理。
- 多平台适配: Azure/OpenAI/GitHub Models 三线可运行。

## 局限与偏见

- 教学广度优先，单点深度需结合官方文档补充。
- 课程更新节奏受维护资源影响，个别依赖可能变化。
- 初学者仍需具备基本 Python/TypeScript 能力。
