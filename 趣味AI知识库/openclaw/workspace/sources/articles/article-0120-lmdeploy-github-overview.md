# InternLM/lmdeploy

## What This Source Is

This source is the LMDeploy repository, a toolkit for compressing, deploying, and serving LLMs with performance-oriented engines.

## Key Points Extracted

- LMDeploy includes two inference engines (TurboMind and PyTorch) with different optimization and usability tradeoffs.
- It provides features for continuous batching, KV cache optimization, quantization, and distributed multi-model serving.
- The toolkit supports broad model families and includes LLM/VLM pipelines plus API-serving guides.
- Installation and quickstart paths are maintained with version-specific CUDA packaging guidance.
- Documentation covers advanced topics such as long-context inference, quantization, and multi-model proxy services.

## Why It Matters

LMDeploy is a mature deployment toolkit for teams balancing high-performance inference with practical deployment and model-compatibility needs.
