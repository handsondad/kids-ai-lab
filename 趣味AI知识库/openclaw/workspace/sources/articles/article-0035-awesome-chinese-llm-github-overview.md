# 文章定位

这是中文 LLM 生态的综合清单仓库，核心定位是汇总中文模型、应用、数据集、训练部署框架、评测基准与教程资源，服务中文场景选型与学习。

## 核心观点

- 以中文生态为中心，覆盖模型、应用、数据、训练、部署、评测、教程全链路。
- 包含大量垂直领域案例（医疗、法律、金融、教育等），有助于场景化落地。
- 整理了中文评测基准和榜单资源，便于建立比较与验证路径。
- 对中文学习者和应用开发者具有高检索价值和本地化参考意义。

## 值得保留的方法或框架

- 中文场景优先导航: 减少跨语言迁移成本。
- 全链路目录法: 从模型到评测形成完整工具地图。
- 场景分域整理: 便于按行业快速定位数据和模型资源。

## 局限与偏见

- 清单规模很大，条目质量和时效性需要二次核验。
- 覆盖广但深度不均，很多条目需回到原仓库进一步验证。
- 部分数据或模型的许可边界需单独确认。
