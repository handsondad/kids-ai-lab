# 文章定位

Aider 是终端优先的 AI 结对编程工具，强调大仓库映射、Git 原生协作和多模型兼容。

## 核心观点

- 通过 repo map 与上下文管理提升大代码库改动质量。
- 与 Git 深度协同，支持自动提交与差异可追踪。
- 支持云端与本地模型，降低供应商绑定。
- 可接入 lint/test 回路，形成改动后自动校验闭环。

## 值得保留的方法或框架

- 终端驱动开发: 将 AI 操作融入现有工程习惯。
- 变更可回溯: 以提交与 diff 保持人类控制权。
- 反馈闭环: 让测试与静态检查成为默认步骤。

## 局限与偏见

- 高度依赖提示质量与上下文选择策略。
- 自动提交需要严格分支与审查规范。
- 模型成本和时延随任务复杂度上升明显。

## 可迁移知识

- 先把 AI 改动纳入标准 Git 流程再扩大使用范围。
- 让 lint/test 自动触发可显著减少返工。
- 终端工作流适合有成熟工程规范的团队。
