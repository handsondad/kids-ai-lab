# Superagent: AI Agent Safety SDK

## Introduction

Superagent is an open-source SDK for AI agent safety. It helps protect your AI applications against prompt injections, data leaks, and harmful outputs. You can embed safety directly into your app and prove compliance to your customers.

## Key Features

*   **Guard:** Detect and block prompt injections, malicious instructions, and unsafe tool calls at runtime.
*   **Redact:** Remove PII, PHI, and secrets from text automatically.
*   **Scan:** Analyze repositories for AI agent-targeted attacks such as repo poisoning and malicious instructions.
*   **Test:** Run red team scenarios against your production agent (coming soon).
*   **Model Agnostic:** Works with any model, including OpenAI, Anthropic, Google, Groq, Bedrock, and more.
*   **Open-Weight Models:** Run the Guard feature on your own infrastructure with low latency.

## Getting Started

To get started with Superagent, you can sign up on their website to get an API key. The SDK is available for both TypeScript and Python and can be installed via npm or pip.

## Integration Options

Superagent offers several integration options:
*   TypeScript SDK
*   Python SDK
*   CLI for testing and automation
*   MCP Server for use with Claude Code and Claude Desktop

Superagent has a Discord community for support and discussion. They also provide documentation, HuggingFace models, and are active on Twitter/X.
