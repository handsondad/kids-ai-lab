# 文章定位

这是一个面向初学者的 Agent 系统课程仓库，以课程单元形式覆盖 Agent 基础、设计模式、RAG、多 Agent、生产部署与协议（含 MCP）等关键主题，适合搭建系统化学习路径。

## 核心观点

- 用课程化结构降低 Agent 学习门槛，强调从概念到代码样例的连贯推进。
- 学习内容围绕真实工程主题组织，而非单点 API 教程。
- 与 Microsoft Agent Framework 与 Azure AI Foundry 生态联动，实践指向明确。
- 多语言与社区协作机制完善，便于全球学习者持续跟进。

## 值得保留的方法或框架

- 章节化课程地图: 先构建能力框架，再补工具细节。
- 主题分层学习: 基础模式 -> 工程化 -> 生产与协议。
- 配套代码样例策略: 每课都有可运行实践，降低知识到行动的落差。

## 局限与偏见

- 课程叙事与微软生态绑定较强，跨生态迁移需要额外对照。
- 对已有工程经验者而言，部分基础章节可能偏慢。
- 仓库定位是教学，不是完整生产框架实现。
