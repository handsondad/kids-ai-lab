# mistralai/mistral-inference

## What This Source Is

This source is the official inference library repository for running open-weight Mistral models locally.

## Key Points Extracted

- The project provides a reference implementation for local CLI and Python inference workflows.
- Installation is available via PyPI and local source setup, with GPU-oriented dependencies.
- It includes examples for chat, function calling, multimodal prompts, and fill-in-the-middle usage.
- Multi-GPU execution paths are documented for larger model variants.
- Deployment notes include containerized serving paths and links to official model/platform documentation.

## Why It Matters

Mistral Inference is useful when teams want direct, official local execution paths for Mistral open-weight models.
