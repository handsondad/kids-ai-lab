# 文章定位

这是一个面向 LLM 全链路的路线图课程仓库，核心价值是把“科学家视角的模型构建”和“工程师视角的系统部署”整合到统一学习路径。

## 核心观点

- 课程按 Fundamentals、Scientist、Engineer 三层组织，便于分阶段学习。
- Scientist 路线覆盖预训练、SFT、偏好对齐、评测、量化与新趋势。
- Engineer 路线覆盖 RAG、Agent、推理优化、部署与安全治理。
- 每个主题配有参考资料，强调可继续深挖的学习索引价值。

## 值得保留的方法或框架

- 双路线课程设计: 同时打通算法侧与工程侧能力。
- 主题-参考联动: 每章都给出可执行延伸资源。
- 路线图学习法: 先建立全局地图，再进入专题实操。

## 局限与偏见

- 内容广度大于深度，具体实现仍需配套实操项目。
- 章节依赖较强，跳读时需要补齐前置概念。
- 一些实践建议对算力或工具环境有一定要求。
