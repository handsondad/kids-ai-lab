# XLA: Accelerated Linear Algebra Compiler

## Introduction

XLA is an open-source machine learning compiler that optimizes execution from major frameworks such as PyTorch, TensorFlow, and JAX across GPUs, CPUs, and accelerators.

## Key Features

- Compiler optimization pipeline for cross-hardware performance.
- Integration pathways with major ML frameworks.
- Contributor-focused repository with development and backend integration docs.
- Active OpenXLA community and large contributor base.

## Getting Started

Framework users generally consume XLA via framework-specific integration docs, while compiler contributors build from source and follow developer guides.

## Notes

XLA is one of the central compiler components in the OpenXLA ecosystem.
