# 文章定位

CAMEL 是面向多代理研究与工程实验的开源框架，核心关注大规模代理系统的扩展规律、状态管理和任务协作。

## 核心观点

- 以多代理“规模规律”研究为核心定位，兼顾工程落地能力。
- 框架强调可演化、可扩展、状态化与 code-as-prompt 原则。
- 覆盖数据生成、任务自动化、仿真等多类实验场景。
- 提供丰富 cookbook 与模块化能力，支持从研究到产品探索。

## 值得保留的方法或框架

- 研究工程一体化: 用统一框架连接实验与应用。
- 规模优先设计: 把代理数量和协作复杂度作为一等约束。
- 状态化协作: 通过记忆和任务流控制增强长链推理稳定性。

## 局限与偏见

- 研究导向功能较多，企业最小落地路径需要裁剪。
- 大规模代理并不总是成本最优方案。
- 场景效果高度依赖任务拆解与评测设计。

## 可迁移知识

- 先做小规模角色协作验证，再逐步扩大代理规模。
- 数据生成能力可用于补齐评测集与回归测试样本。
- 多代理系统需要同步设计观测与成本治理策略。
