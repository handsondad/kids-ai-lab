# LLM-AWQ: Activation-Aware Weight Quantization

## Introduction

LLM-AWQ is the reference project for AWQ, a low-bit weight quantization method for accelerating and compressing LLM inference.

## Key Features

- AWQ search and quantization workflows for INT3/INT4 paths.
- Precomputed model zoo for major model families.
- Efficient CUDA kernels and memory-efficient 4-bit linear layers.
- TinyChat integration for edge and cloud inference use cases.
- Coverage for LLM and vision-language model scenarios.

## Getting Started

Clone the repo, install dependencies, then run AWQ scripts for search, quantization, and evaluation.

## Notes

LLM-AWQ is a core reference for practical activation-aware quantization in production-oriented LLM inference.
