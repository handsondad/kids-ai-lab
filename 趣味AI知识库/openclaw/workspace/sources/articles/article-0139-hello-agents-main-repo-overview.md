# hello-agents-main 仓库总览提炼

## What This Source Is

这是对 hello-agents-main 的结构化提炼，目标是把从 Agent 基础到系统工程落地的完整学习链路沉淀为可复用知识资产。

## Core Positioning

- 面向 AI Native Agent 构建者的系统化开源教程。
- 采用章节化推进：基础认知 -> 范式与框架实践 -> 高级系统能力 -> 综合项目 -> 毕业设计。
- 强调从使用现有框架到自建 HelloAgents 框架，再到真实应用交付。

## Curriculum Spine (Chapter 1-16)

1. chapter1-3：智能体概念、发展史、LLM 基础。
2. chapter4-7：经典范式、低代码平台、框架实践、自建 Agent 框架。
3. chapter8-12：记忆检索、上下文工程、通信协议、Agentic-RL、性能评估。
4. chapter13-15：旅行助手、深度研究助手、赛博小镇等综合案例。
5. chapter16：毕业设计与延展路线。

## Engineering Assets Worth Reusing

- code/chapter7-12：框架核心能力、协议、训练与评估脚本。
- code/chapter13-15：多智能体应用与前后端工程模板。
- Extra-Chapter 与 Co-creation-projects：社区增量实践和共创项目资产。

## Why It Matters for KB

hello-agents 的价值在于“系统工程完整度”：不仅教会如何调用模型，更教会如何设计、实现、评测并交付智能体系统。

## Practical Takeaways

- 可以作为 Agent 工程化学习主线，与传统 LLM 教程形成互补。
- chapter7-12 适合沉淀为框架与能力模块化方法卡。
- chapter13-15 适合沉淀为应用交付模板与项目复盘模板。
