# 文章定位

这是提示工程领域的综合导航仓库，核心定位是整合提示技术、应用案例、模型信息、风险治理与学习资料，形成可检索的知识入口。

## 核心观点

- 提示工程被定义为面向 LLM 能力发挥和约束控制的关键工程能力。
- 资源覆盖从基础提示到 CoT、ReAct、RAG、函数调用等进阶技术。
- 提供应用场景、提示模板库、模型专题与工具清单。
- 同时强调风险与误用治理，包括对抗提示、事实性和偏见问题。

## 值得保留的方法或框架

- 技术谱系化组织: 从入门到高级技巧形成连续学习链。
- 模型与任务双索引: 便于按应用目标快速定位实践路径。
- 风险前置: 在技巧学习中同步引入安全与可靠性视角。

## 局限与偏见

- 主题更新快，具体技巧效果会随模型演化而变化。
- 清单导向强，落地仍需结合具体业务任务评测。
- 不同语言与场景下提示可迁移性有限。
