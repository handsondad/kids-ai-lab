# OpenXLA: Open ML Compiler Ecosystem

## Introduction

OpenXLA is a community-driven ML compiler ecosystem focused on reducing infrastructure fragmentation across frameworks and hardware backends.

## Key Features

- Ecosystem-level governance and collaboration model.
- Core projects include XLA, StableHLO, Shardy, and tooling repos.
- Emphasis on interoperability between ML frameworks and compiler stacks.
- Public community channels for releases, design discussions, and meetings.

## Getting Started

Developers typically start from specific subprojects (for example XLA or StableHLO) and follow each repository's build and contribution guides.

## Notes

OpenXLA acts as an umbrella coordination layer for compiler and IR standardization in modern ML systems.
