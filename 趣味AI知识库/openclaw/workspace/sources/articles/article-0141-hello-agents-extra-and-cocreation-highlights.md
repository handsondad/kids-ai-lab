# hello-agents 社区增量层提炼

## What This Source Is

这是对 hello-agents 社区增量内容的补充提炼，覆盖 Extra-Chapter 的高价值实践文章与 Co-creation-projects 的共创项目机制。

## Selected High-Value Themes

- Agent Skills 与 MCP 的分层协作模式与上下文优化策略。
- Code Agent 工程实践中的常见陷阱与可诊断性原则。
- 共创项目目录的命名规范、结构规范与交付流程。

## Why It Matters

社区增量层提供了主教程之外的“实战反思和方法沉淀”，能够补齐工程落地中的经验型知识。

## Practical Takeaways

1. 在复杂工具系统中，连接能力与领域能力应分层设计。
2. Agent 工程优先保证可诊断性，再追求工具链复杂度。
3. 共创项目可作为毕业设计和团队协作的实践模板。
