# Dagster: Data Asset-Oriented Orchestration

## Introduction

Dagster is a cloud-native orchestration platform for developing, producing, and observing data assets across the full data lifecycle.

## Key Features

- Declarative asset definitions in Python.
- Built-in lineage, observability, and diagnostics.
- Strong testing model from local development to production.
- Broad integrations across modern data stack tooling.
- Multi-tenant orchestration capabilities for larger organizations.

## Getting Started

Install dagster packages from PyPI and follow quickstart docs to define and run asset graphs.

## Notes

Dagster is well-suited for teams standardizing reliable data pipelines and asset governance.
