# Claude Code x OpenClaw 中文教程仓库提炼

## What This Source Is

这是对 Claude-Code-x-OpenClaw-Guide-Zh 仓库的结构化提炼，核心目标是把 25 篇教程沉淀为可检索、可执行的双栈知识路径。

## Repository Scope

- Claude Code 主线：安装、命令、MCP、Hooks、Subagent、Skills、Plugins、Agent SDK、Remote Control、Channels 与计划任务。
- OpenClaw 主线：项目介绍、安装、模型配置、消息平台、技能系统、记忆系统、多 Agent、Docker、安全与 FAQ。

## Key Signals

1. 该仓库强调“官方能力与社区资源分层”，避免把第三方生态误判为官方内置。
2. Claude Code 部分以工程自动化链路为核心：MCP + Hooks + Channels + SDK。
3. OpenClaw 部分以运行面和治理面并重：模型路由、技能记忆、沙箱与安全。

## High-Value Takeaways

- Claude Code：应优先建立“事件驱动自动化”心智，而不是只记命令。
- OpenClaw：应优先建立“本地网关 + 安全隔离 + 可观测运行”的系统观。
- 双栈结合：可形成“开发端（Claude Code）+ 运营端（OpenClaw）”的一体化 Agent 工作流。
