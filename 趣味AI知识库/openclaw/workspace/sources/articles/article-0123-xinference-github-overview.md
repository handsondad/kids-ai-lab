# xorbitsai/inference

## What This Source Is

This source is the Xorbits Inference (Xinference) repository for unified serving of language, speech, and multimodal models.

## Key Points Extracted

- Xinference provides OpenAI-compatible REST APIs plus RPC, CLI, and Web UI interfaces.
- It supports heterogeneous and distributed deployment across single-node and multi-node environments.
- Built-in integrations include common agent and app frameworks, with active model support updates.
- Quickstart paths cover local pip install, Docker deployment, and Kubernetes Helm deployment.
- The project positions itself as a production-ready serving layer with broad built-in model and engine support.

## Why It Matters

Xinference is valuable for teams wanting one serving layer across multiple model types and deployment topologies.
