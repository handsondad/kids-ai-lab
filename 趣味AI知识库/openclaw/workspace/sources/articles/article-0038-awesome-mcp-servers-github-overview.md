# 文章定位

Awesome MCP Servers 是 MCP 服务器生态索引，覆盖客户端、教程、社区与大量垂直领域实现，适合作为 Agent 工具接入的总导航。

## 核心观点

- 通过分类目录降低 MCP 工具发现成本。
- 同时覆盖官方实现与社区实现，便于对比选型。
- 提供语言、运行范围、平台等标记，便于部署判断。
- 与在线目录联动，形成持续更新的生态视图。

## 值得保留的方法或框架

- 生态清单法: 先用目录筛选，再进入单项目验证。
- 标签驱动选型: 按语言和运行环境快速初筛。
- 客户端 + 服务器双向导航: 降低接入断层。

## 局限与偏见

- 条目规模巨大，质量与维护状态参差不齐。
- 清单本身不提供统一 SLA，需要逐个仓库验证。
- 新增速度快，版本变化可能导致文档与实现不同步。
