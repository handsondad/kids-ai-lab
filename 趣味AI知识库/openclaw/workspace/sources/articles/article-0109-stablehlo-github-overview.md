# StableHLO: Backward-Compatible ML Compute Opset

## Introduction

StableHLO is an operation set and portability layer for ML frameworks and compilers, designed to improve interoperability and long-term compatibility.

## Key Features

- Stable operation set inspired by HLO/MHLO.
- Serialization and versioning with compatibility guarantees.
- C++ and Python implementation with MLIR tooling.
- Build and integration paths for compiler and framework ecosystems.

## Getting Started

Build with CMake/Ninja, optionally enable Python bindings, and use StableHLO artifacts in compiler pipelines or conversion flows.

## Notes

StableHLO is a foundational compatibility layer in the OpenXLA ecosystem.
