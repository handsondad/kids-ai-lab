# Boofuzz: Network Protocol Fuzzing for Humans

## Introduction

Boofuzz is a Python-based fuzzing framework and a successor to Sulley. It is designed for protocol fuzzing with practical tooling for failure detection, crash reproduction, and test data recording.

## Key Features

- Fast fuzz-data generation and protocol test scripting.
- Extensible instrumentation and failure detection.
- Built-in support for diverse communication mediums.
- Clear test recording with CSV export support.
- Active documentation and examples for quick onboarding.

## Getting Started

Install with `pip install boofuzz`, then define fuzzing sessions in Python scripts. The framework is suitable for protocol robustness testing and security research workflows.

## Notes

Boofuzz is widely used in security testing contexts where repeatable, scriptable fuzzing is required.
