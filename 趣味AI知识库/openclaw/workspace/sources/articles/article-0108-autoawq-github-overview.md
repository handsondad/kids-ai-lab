# AutoAWQ: Practical AWQ Quantization Toolkit

## Introduction

AutoAWQ is a toolkit that implements AWQ-based 4-bit quantization for LLM inference acceleration and memory reduction.

## Key Features

- Easy quantization and inference workflows with Python APIs.
- Multiple install variants for kernels and hardware paths.
- Performance-oriented fused modules and benchmark guidance.
- Broad model compatibility and integration with surrounding tooling.

## Getting Started

Install via pip (`autoawq` variants), then run quantization and inference examples from the project docs.

## Notes

The repository is archived and officially deprecated; maintainers point users to newer alternatives in the announcement.
