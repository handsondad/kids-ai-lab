# 核心提炼

- happy-llm 是从“理解原理”到“亲手构建”再到“应用落地”的全流程课程仓。
- 主价值在于章节脊柱清晰：1-4 理论，5-6 训练实现，7 应用实践。
- chapter5/chapter6 提供了可迁移的训练工程骨架，不仅是教学文本。
- chapter7 把 Eval、RAG、Agent 串在同一应用层框架里，适合做系统化入门。
- Extra-Chapter 提供社区增量专题，可作为高时效知识补充层。
- chapter5/chapter6/chapter7 的代码可进一步沉淀为训练与应用模板库。

## 可沉淀的知识资产

- 主题卡：LLM 理论到实战的进阶路线图。
- 主题卡：从零搭建与训练管线方法（LLaMA2 + Transformers 体系）。
- 主题卡：Eval/RAG/Agent 应用层方法与最小实现路径。
- 主题卡：Extra-Chapter 专题方法（小模型决策、生成控制、thinking budget、VLM 拼接、专业 RAG）。
- 主题卡：代码资产工程模板（训练 SOP、数据掩码、DeepSpeed、最小 RAG、函数调用 Agent）。
- 主题卡：Agent Web Demo 可视化交互与演示化上线模板。
- 主题卡：Chapter6 notebook 复现实验单（从实验到脚本迁移前检查）。
- 主题卡：章节-脚本-产物实施矩阵（复现推进与验收清单）。
- 主题卡：RAG 风险与加固清单（检索质量与可观测性）。
- 主题卡：Agent 风险与治理清单（工具执行与安全审计）。
- 主题卡：文本数据处理基础、Transformer 架构导读与 chapter2 最小代码模板。
- 工具卡：happy-llm-main 作为课程化训练与应用模板仓。
- 合集卡：从基础理论到工程实战的学习路径。
