# 来源概览

从 GitHub 仓库 `Awesome-Auto-Research-Tools` 提取的 AI 科研自动化工具精选列表，涵盖端到端研究系统、文献综述、实验自动化等完整研究生命周期。

## 核心分类

### 1. 端到端自主研究系统

自动化完整研究流程：想法 → 实验 → 论文

**顶级项目**：
- **AI-Scientist** (Sakana AI, 4000+ stars): 首个全面自动化开放式科学发现的系统
- **AI-Scientist-v2**: 使用智能体树搜索，生成首个通过同行评审的AI撰写论文
- **RD-Agent** (Microsoft, 3000+ stars): 自动化R&D流程，量化金融、Kaggle自动化
- **AI-Researcher** (HKUDS, 1800+ stars): NeurIPS 2025 Spotlight
- **Agent Laboratory** (900+ stars): 端到端自主研究工作流
- **Biomni** (Stanford, 600+ stars): 生物医学AI智能体
- **InternAgent** (Shanghai AI Lab, 400+ stars): 跨学科研究智能体

### 2. 深度研究与文献综合

自动化信息收集、文献综述和报告生成

**核心工具**：
- **STORM** (Stanford, 15000+ stars): LLM驱动的知识管理系统，生成维基百科式长文章
- **GPT Researcher** (18000+ stars): 自主深度网络和本地研究，生成5-6页报告
- **DeerFlow** (ByteDance, 2500+ stars): 开源SuperAgent工具
- **ChatPaper** (7000+ stars): 使用ChatGPT总结arXiv论文
- **Tongyi DeepResearch** (Alibaba, 1000+ stars): 30.5B参数智能体LLM
- **PaperQA2** (3500+ stars): 高精度科学文档RAG，ICLR发表
- **OpenScholar** (600+ stars): 搜索4500万开放获取论文，Nature发表

### 3. 自动化实验与代码智能体

自动化编码、实验执行和迭代优化

**核心工具**：
- **AutoGPT** (170000+ stars): 最早的自主AI智能体框架之一
- **OpenHands** (40000+ stars): AI驱动的软件开发平台，SWE-Bench 72%
- **Aider** (30000+ stars): 终端AI结对编程
- **SWE-agent** (Princeton, 14000+ stars): 将LLM转变为软件工程智能体
- **AIDE** (1500+ stars): AI驱动的ML代码优化，4倍Kaggle奖牌
- **MLE-agent** (800+ stars): ML工程智能伴侣

### 4. 研究技能与插件集合

可重用的技能集和插件生态系统

**核心资源**：
- **scientific-agent-skills** (500+ stars): 133个即用型科学技能
- **AI-Research-SKILLs** (300+ stars): 86个技能，22个类别

## 关键洞察

1. **研究流程自动化**: 从文献综述到论文写作的完整流程自动化
2. **多智能体协作**: 专业化智能体协同完成复杂研究任务
3. **领域专业化**: 生物医学、量化金融、跨学科研究等垂直领域工具
4. **开源生态**: 大部分工具开源，支持多种LLM后端
