# 核心提炼

- 这套仓库可视为 Agent 工程的双路线教材：Claude Code 偏开发自动化，OpenClaw 偏助手运行与治理。
- Claude Code 的高价值能力集中在 MCP、Hooks、Subagent、Channels、Agent SDK 的组合。
- OpenClaw 的高价值能力集中在安装稳定性、模型路由、技能与记忆、沙箱与安全。
