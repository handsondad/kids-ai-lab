# 核心观点

- **模型能力升级**：GPT-5 引入 o3 推理，数学 AIME 测试达 94.6%；Claude 4.5/4.6 在 SWE-bench 编程测试中突破 80.9%；Gemini 3 支持 200万+ token 且原生多模态。
- **Agent 框架成熟**：LangGraph、CrewAI 等框架让 Agent 能够自主执行长达 30 小时的复杂任务。
- **性价比之战**：DeepSeek-V3 成本仅为 GPT-4 的 1/7，引领大模型走向普惠化。
- **搜索向 Agent 进化**：Perplexity Computer 能够调度 19 个模型完成端到端项目。
