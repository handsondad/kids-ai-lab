# 核心提炼

- 该 README 可作为一份完整的 LLM 学习导航，从基础到工程部署形成闭环。
- 链接资产可分为五类：入口、Notebooks、Fundamentals、Scientist、Engineer。
- 对知识库价值最高的不是“保存链接”，而是“按场景组织链接 + 给出使用顺序”。

## 可拆出的卡片

- Foundations 资源地图卡：聚焦数学、Python、NN、NLP。
- Scientist 资源地图卡：聚焦训练与模型能力提升。
- Engineer 资源地图卡：聚焦 RAG、Agents、部署、安全。
- Notebook 实操卡：聚焦可直接复现的 Colab 路径。
- 链接内容索引卡：逐链接内容摘要与检索定位。
- 30 天执行卡：按周目标推进学习与项目产出。
- 合集卡：把上述卡片按学习顺序串成路线。

## 学习者会怎么问

- 我现在是入门阶段，哪些链接先看？
- 我想做 RAG/Agent 应用，哪些链接最实用？
- 我需要做模型训练和评测，先搭什么工具链？
- 我已经能跑 Demo，下一步怎么补齐部署和安全？
