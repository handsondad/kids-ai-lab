# 核心提炼

- hello-agents 形成了从 Agent 基础到系统交付的端到端学习路线。
- chapter7 是转折点：从“用框架”切换到“造框架”。
- chapter8-12 构成高级能力闭环：Memory/RAG、上下文工程、协议、训练、评测。
- chapter13-15 提供可运行的工程案例，强调产品化落地与可复盘。
