# 核心观点

- **OpenClaw 昵称体系**：主项目被称为“龙虾”或“小龙虾”。“养龙虾”指部署和运行该智能体。
- **MimiClaw (xiaomiclaw)**：极轻量级分支，用 C 语言编写，专为 ESP32-S3 等嵌入式芯片设计。
- **qclaw**：高性能/量化分支，旨在低资源环境下快速运行智能体逻辑。
- **dumate / DuMate**：一种 AI 伙伴/副驾驶工具，强调“陪伴”与“协作”属性，常与 OpenClaw 的个人助理功能结合使用。
- **workbuddy (办公伙伴)**：基于 OpenClaw 的办公垂直领域封装，预集成了邮件处理、日程管理等技能。
- **trae-solo**：来自 Trae IDE 生态，允许智能体以“单兵作战”模式脱离编辑器执行复杂的系统级任务。

## 可拆出的卡片
