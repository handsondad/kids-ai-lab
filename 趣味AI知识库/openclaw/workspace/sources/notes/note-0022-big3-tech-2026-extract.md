# 核心观点

- **Anthropic (Claude 3.7 / 4.6)**：主打 **混合推理 (Hybrid Reasoning)**。3.7 是首个将标准 LLM 与深度思考集于一身的模型。4.6 进一步将 **上下文窗口提升至 1M**。**Claude Code** 标志着从助手向终端智能体的跨越。
- **OpenAI (GPT-4.5 / o-series)**：明确智力两轴：**无监督学习 (GPT-4.5)** 提升常识与 EQ，**推理扩展 (o1/o3)** 解决逻辑难题。**Operator** 开启自主网页执行时代。
- **Google (Gemini 2.0)**：定义 **智能体时代 (Agentic Era)**。2.0 系列原生支持多模态输出与工具使用。**Project Mariner** 展示了最强的浏览器操作能力。

## 可拆出的卡片

- **主题卡**：混合推理架构 (Hybrid Reasoning)。
- **工具卡**：Claude 3.7 Sonnet / 4.6, GPT-4.5, Gemini 2.0 Flash。
- **工具卡**：Claude Code, OpenAI Operator, Project Mariner。
