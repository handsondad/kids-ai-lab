# Dagster

## Introduction

Dagster is a Python-centric orchestration platform for reliable data asset pipelines.

## Key Features

- Asset graph and lineage model.
- Testing and deployment-friendly workflow.
- Built-in observability and diagnostics.
- Wide ecosystem integrations.

## Getting Started

Install Dagster packages and follow the quickstart to define assets and run orchestration jobs.
