# Windsurf

## 工具定位

Windsurf是Codeium推出的AI原生IDE，基于VS Code Fork开发，完全免费，主打性价比和Agent Flow协作模式，适合预算有限的开发者和新手入门。

## 适用场景

- **预算有限**: 完全免费，无限制使用
- **新手入门**: 上手简单，新手友好
- **中小型项目**: 不需要超大上下文
- **尝试新范式**: Agent Flow协作模式

## 核心能力

### 1. 完全免费
- 无需付费
- 无限制使用
- 无功能限制

### 2. AI原生IDE
- 从底层为AI设计
- VS Code Fork架构
- 自研Codeium模型

### 3. Agent Flow
- 创新协作模式
- 智能工作流
- 任务分解能力

### 4. 代码补全
- 行/块级补全
- 上下文理解能力强
- 响应速度快

## 上手路径

### 第一步：下载安装
- 访问 https://codeium.com/windsurf
- 下载对应平台版本
- 安装并启动

### 第二步：配置项目
- 打开项目文件夹
- Windsurf自动索引代码库
- 开始使用AI功能

### 第三步：使用Agent Flow
- 尝试Agent Flow协作模式
- 描述任务目标
- 让AI自主完成部分工作

## 选择边界

✅ 预算有限（免费）
