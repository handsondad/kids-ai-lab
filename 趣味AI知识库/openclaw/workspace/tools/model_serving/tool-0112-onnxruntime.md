# ONNX Runtime

## Introduction

ONNX Runtime is a high-performance runtime for executing and optimizing machine learning models across hardware platforms and operating systems.

## Key Features

- Cross-platform inference and training acceleration with hardware-aware execution.
- Broad framework compatibility and support for both deep learning and classical ML.
- Graph optimizations, execution providers, and deployment-oriented runtime tooling.
- Multi-language APIs and ecosystem examples for production integration.

## Getting Started

Follow onnxruntime.ai docs for installation and execution-provider selection, then validate performance using model-specific inference examples.
