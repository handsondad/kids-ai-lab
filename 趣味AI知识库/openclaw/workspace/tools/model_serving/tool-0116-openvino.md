# OpenVINO

## Introduction

OpenVINO is an open-source toolkit for optimizing and deploying deep learning inference across edge and cloud environments.

## Key Features

- Model conversion and deployment support from major training frameworks.
- Device flexibility across CPU, GPU, and NPU with performance-oriented runtime paths.
- Integrations for GenAI, ONNX Runtime execution provider, and ecosystem tooling.
- Rich tutorials, notebooks, and production-oriented documentation.

## Getting Started

Install with `pip install -U openvino`, then follow quickstart tutorials to convert, compile, and run models on target devices.
