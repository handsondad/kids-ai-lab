# LLM-AWQ

## Introduction

LLM-AWQ is the core reference implementation of activation-aware weight quantization for low-bit LLM inference.

## Key Features

- AWQ search and quantization pipelines.
- INT4-oriented efficient kernels.
- Model zoo and script-based reproducible workflows.
- TinyChat integration for edge and cloud serving.

## Getting Started

Set up the environment, install package dependencies, and execute AWQ scripts for search, quantization, and evaluation.
