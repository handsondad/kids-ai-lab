# XLA

## Introduction

XLA is an ML compiler that optimizes model execution from major frameworks across heterogeneous hardware.

## Key Features

- Compiler optimizations for performance portability.
- Framework integrations with PyTorch, TensorFlow, and JAX.
- Contributor tooling for backend and compiler development.
- Active community and ecosystem alignment under OpenXLA.

## Getting Started

Framework users adopt XLA through framework docs; compiler developers use source build and contributor guides from the repository.
