# DeepSpeed

## Introduction

DeepSpeed is a performance-focused optimization stack for large-scale deep learning workloads.

## Key Features

- ZeRO-based memory and parallelism optimizations.
- Support for high-scale distributed training and inference.
- Integration with major model training frameworks.
- Tooling for environment validation and advanced builds.

## Getting Started

Install after PyTorch setup, then integrate DeepSpeed runtime/config into training code for efficiency gains on large models.
