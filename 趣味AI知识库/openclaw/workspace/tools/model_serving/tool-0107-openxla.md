# OpenXLA

## Introduction

OpenXLA is a cross-organization compiler ecosystem focused on interoperable ML compilation infrastructure.

## Key Features

- Community-governed ecosystem and standards work.
- Multiple core repositories for compiler, IR, and tooling.
- Framework and hardware interoperability focus.
- Public community channels and collaborative development.

## Getting Started

Start with target subprojects such as XLA or StableHLO and follow each repository's developer documentation.
