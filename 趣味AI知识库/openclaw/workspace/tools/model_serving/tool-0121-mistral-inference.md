# Mistral Inference

## Introduction

Mistral Inference is the official open-source runtime library for local execution of Mistral models.

## Key Features

- Official CLI and Python workflows for chat and generation.
- Support for instruction following, function calling, multimodal prompts, and FIM use cases.
- Multi-GPU execution patterns for larger model families.
- Reference deployment material aligned with Mistral model ecosystem.

## Getting Started

Install via pip or poetry, download model weights, then run `mistral-demo` and `mistral-chat` commands to validate local inference.
