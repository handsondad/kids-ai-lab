# TensorRT-LLM

## Introduction

TensorRT-LLM provides production-focused inference acceleration for LLM workloads on NVIDIA hardware.

## Key Features

- High-performance decoding and memory optimizations.
- Quantization support across multiple precision formats.
- Python API with scalable runtime options.
- Integration with NVIDIA and Triton serving ecosystem.

## Getting Started

Use official install and quick-start docs to configure supported hardware and deploy optimized inference services.
