# MLC-LLM

## Introduction

MLC-LLM is a compiler-driven deployment stack that optimizes and serves LLMs across a wide range of runtime platforms.

## Key Features

- Unified ML compilation and inference engine strategy across desktop, server, web, and mobile.
- Multi-platform backend support including CUDA, Metal, Vulkan, WebGPU, and mobile GPU paths.
- OpenAI-compatible serving interfaces with language SDK integrations.
- Documentation-first onboarding for installation, quick start, and production usage.

## Getting Started

Use official docs for installation and quickstart, then select platform-specific backend paths to compile and deploy target models.
