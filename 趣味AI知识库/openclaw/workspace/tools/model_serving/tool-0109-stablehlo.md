# StableHLO

## Introduction

StableHLO defines a stable ML compute opset and compatibility model for cross-framework, cross-compiler workflows.

## Key Features

- Serialization/versioning with compatibility guarantees.
- MLIR-based implementation and Python bindings.
- Spec and tooling for compiler interop.
- Integration support for conversion workflows.

## Getting Started

Build with CMake/Ninja, optionally enable Python bindings, and use StableHLO artifacts within compiler pipelines.
