# LMDeploy

## Introduction

LMDeploy is a deployment toolkit for LLM compression, inference, and serving with strong focus on performance and practical deployment workflows.

## Key Features

- Dual-engine design (TurboMind and PyTorch) for different performance/usability needs.
- Support for batching, quantization, and distributed multi-model service patterns.
- Broad model compatibility for both LLM and VLM workflows.
- Comprehensive docs for quickstart, API serving, and advanced inference topics.

## Getting Started

Install via pip in supported Python/CUDA environments, then start with pipeline or API server tutorials based on deployment goals.
