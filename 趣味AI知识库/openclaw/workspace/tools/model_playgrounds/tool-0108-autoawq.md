# AutoAWQ

## Introduction

AutoAWQ is a practical package for 4-bit AWQ model quantization and accelerated inference.

## Key Features

- Multiple install modes and kernel options.
- Quantization/inference examples and benchmarks.
- Memory and throughput improvements for supported models.
- Broad model support in historical releases.

## Getting Started

Install via pip and run examples for quantization and generation workflows.

Project status is archived/deprecated, with migration guidance to successor tooling.
