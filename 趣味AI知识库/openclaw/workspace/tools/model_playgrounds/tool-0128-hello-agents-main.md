# hello-agents-main

## Introduction

hello-agents-main 是面向 AI Native Agent 构建者的系统化开源教程仓，覆盖从基础认知到工程交付的完整路径。

## Key Features

- 五段式课程结构：基础理论、框架构建、高级能力、综合案例、毕业设计。
- 自建 HelloAgents 框架主线：从用框架到造框架。
- 高级能力闭环：Memory/RAG、上下文工程、MCP/A2A/ANP、Agentic-RL、评估。
- 案例化交付：旅行助手、深度研究助手、赛博小镇等综合工程项目。

## Getting Started

建议按章节主线学习并同步运行 code 目录示例，优先完成 chapter7-12 再进入 chapter13-15 案例开发。
