# 工具定位

GPT-5是OpenAI于2026年4月发布的最新大语言模型，在Chatbot Arena榜单中以1428 ELO分数排名第一，擅长复杂推理、长文档处理和多模态理解。

## 适用场景

- 专业工作和复杂推理任务
- 长文档分析和处理（支持100万Token上下文）
- 多模态任务处理（文本+图像）
- 智能体执行和工具调用

## 核心能力

- **Thinking模式**: 展示推理过程，透明化思考链
- **智能体执行**: 可自主调用工具、执行任务
- **多模态融合**: 文本+图像输入，支持1M+上下文
- **长上下文**: 100万Token窗口

## 上手路径

1. 先通过ChatGPT或API体验基础对话能力。
2. 尝试Thinking模式理解复杂推理过程。
3. 引入到专业工作流，如文档分析、代码生成。

## 选择边界

- 定价较高：输入$2.50/M tokens，输出$15.00/M tokens
- 需要网络访问，不适合离线场景
- 企业版需要额外配置和安全审查
