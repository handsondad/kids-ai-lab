# happy-llm-main

## Introduction

happy-llm-main 是一个系统化的大模型学习仓，面向“从原理到实战”的进阶学习，强调可复现、可迁移、可落地。

## Key Features

- 章节化课程主线：NLP -> Transformer -> PLM -> LLM -> 训练 -> 应用。
- 双轨训练路径：先手写 LLaMA2 关键模块，再迁移到 Transformers 工程管线。
- 应用层闭环：覆盖 Eval、RAG、Agent 的最小实现与方法论。
- 支持社区扩展：Extra-Chapter 持续吸收专题实践与前沿技术总结。

## Getting Started

建议按三段式学习：先完成理论章节，再复现 chapter5/chapter6 训练代码，最后完成 chapter7 的应用闭环实践。
