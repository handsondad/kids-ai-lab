# 工具定位

OpenHands 是面向开发任务的 AI 代理体系，提供 SDK、CLI、GUI 到云端/企业部署的完整使用路径。

## 适用场景

- 你要让编码代理在本地和团队环境中持续协作
- 你要从个人助手升级到多用户研发平台
- 你要为企业研发流程引入权限与协作治理

## 核心能力

- 多入口统一: SDK、CLI、GUI 可按角色自由接入
- 多层部署路径: 本地验证、云端试用、企业私有化
- 协作集成: 支持与常见工程系统联动扩展

## 上手路径

1. 先使用 CLI 跑通单任务开发流程。
2. 再用本地 GUI 验证团队协作体验。
3. 最后按治理需求评估云端或企业部署。

## 选择边界

- 复杂编码任务仍需人工代码审查与测试兜底。
- 企业部署需提前明确授权和合规边界。
- 模型与工具权限配置直接影响代理上限。
