# self-llm-master

## Introduction

self-llm-master 是一个面向中文学习者的开源大模型实操仓库，强调从环境准备到应用落地的全流程学习。

## Key Features

- 多模型、多平台实战教程，覆盖部署、调用、集成、微调与评测。
- 提供 FastAPI、WebDemo、LangChain、Docker 等常见工程路径。
- 包含案例化 Example 模块，支持从教程迁移到真实项目。
- 支持跨硬件场景（如 AMD、Ascend、Apple M）学习与验证。

## Getting Started

按四阶段路线学习：先环境配置，再部署调用，再应用集成，最后进行 LoRA/QLoRA 等微调与评测。
