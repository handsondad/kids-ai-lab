# 工具定位

Awesome MCP Servers 是 MCP 生态总导航，用于快速发现可接入的服务器、教程与客户端，适合 Agent 工具链选型起点。

## 适用场景

- 你要为代理系统挑选可落地 MCP 服务
- 你要按语言/平台筛选可部署的实现
- 你要快速了解 MCP 生态版图和演进方向

## 核心能力

- 大规模目录化: 覆盖多行业 MCP 服务器
- 标记体系: 语言、云/本地、平台等可快速筛选
- 社区联动: 与在线目录互补，更新频率高

## 上手路径

1. 先按你的业务域和运行环境筛一轮候选。
2. 再检查每个仓库的维护活跃度和许可策略。
3. 小规模接入验证后再纳入正式工具清单。

## 选择边界

- 清单不是质量保证，必须二次尽调。
- 文档与实现可能存在版本时差。
- 生产环境需要额外安全和观测治理。
