# 工具定位

MCP for Beginners 是结构化学习资源，适合用课程方式系统掌握 MCP，从概念、安全到服务实现逐步推进。

## 适用场景

- 你要系统学习 MCP 而不只是看碎片教程
- 你要为团队做统一 MCP 入门训练
- 你要从实验走向可部署的 MCP 服务实践

## 核心能力

- 模块化路径: 基础、构建、进阶、最佳实践
- 多语言支持: C#/Java/JS/Python/TS/Rust
- 配套实验: 包含测试、部署、主机配置等实操

## 上手路径

1. 先完成 00-03 模块建立概念与最小实现。
2. 再进入实践模块补齐安全、测试和部署能力。
3. 最后做 Lab 路线，形成可迁移的工程模板。

## 选择边界

- 属于学习课程，不等同生产框架本体。
- 仍需结合具体 SDK 文档做实现细化。
- 部分高级实验依赖云资源和环境配置。
