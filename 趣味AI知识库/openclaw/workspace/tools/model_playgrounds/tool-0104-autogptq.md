# AutoGPTQ

## Introduction

AutoGPTQ is a toolkit for GPTQ quantization and inference workflows on large language models.

## Key Features

- Model quantization and loading APIs.
- Multiple backend and kernel options.
- Integration-friendly with transformers ecosystem.
- Quantization benchmarks and usage examples.

## Getting Started

Install AutoGPTQ from pip or source, run quantization scripts, and load quantized checkpoints for inference.

## Notes

The repository is archived and unmaintained; the project recommends migration to GPTQModel.
