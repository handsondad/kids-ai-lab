# 工具定位

Awesome Chinese LLM 是中文大模型生态的综合导航清单，适合在中文语境下做模型、数据、评测与应用方案的快速盘点。

## 适用场景

- 你要在中文场景中筛选可用模型和部署路线
- 你要快速查找垂直领域案例与对应数据资源
- 你要建立中文基准评测与教程学习入口

## 核心能力

- 全链路目录: 模型、应用、数据、训练、部署、评测、教程一站式导航
- 中文场景聚焦: 适合本地化需求与中文任务选型
- 场景化归类: 医疗、法律、金融等垂直方向检索效率高

## 上手路径

1. 先从目录总览定位你当前阶段（模型、数据或评测）。
2. 再按场景筛出候选仓库并核验许可与维护状态。
3. 最后用小样本实验验证可行性并沉淀选型结论。

## 选择边界

- 清单规模大，信息时效和质量需逐条核查。
- 不同项目许可差异明显，商用前要单独确认。
- 适合作为导航入口，不替代完整技术评测。
