# 工具定位

Prompt Engineering Guide 是提示工程领域的综合学习与检索入口，适合系统梳理提示技巧、应用模式与风险治理要点。

## 适用场景

- 你要系统学习从零样本到 ReAct/RAG 的提示方法
- 你需要按任务类型快速查找可复用提示模式
- 你希望把提示设计与安全风险评估一起推进

## 核心能力

- 技术体系化: 从基础、技巧到应用和模型专题完整覆盖
- 提示库化: 提供多任务提示模式与实践入口
- 风险并行: 同步提供对抗提示、事实性和偏见相关内容

## 上手路径

1. 先完成基础和技巧章节，建立稳定的提示构造框架。
2. 再按应用任务挑选提示模式并做小样本验证。
3. 最后加入风险章节与评测流程，形成可持续迭代机制。

## 选择边界

- 提示技巧依赖模型特性，跨模型迁移需重新验证。
- 该指南是导航与方法库，不直接替代业务评测流程。
- 对复杂系统仍需结合编排框架与工具链。
