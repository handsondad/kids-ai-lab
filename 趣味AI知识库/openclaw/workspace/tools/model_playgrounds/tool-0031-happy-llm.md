# 工具定位

Happy-LLM 是面向中文学习者的大模型系统教程项目，适合按章节完成从原理理解到训练与应用实践的连续学习。

## 适用场景

- 你希望系统学习 LLM，而不是碎片化看资料
- 你要把 Transformer、微调、RAG、Agent 串成完整知识链
- 你想通过开源教程和实践项目快速建立实操能力

## 核心能力

- 章节式学习: 从 NLP 与 Transformer 到训练和应用逐层推进
- 中文实践友好: 术语、案例和讲解更贴近中文学习语境
- 社区共创更新: 通过扩展章节持续吸收前沿主题

## 上手路径

1. 先跑通基础章节，建立 Transformer 与 LLM 训练骨架。
2. 再做第五到第七章实战内容，完成从训练到应用的闭环。
3. 最后结合 Extra Chapter 扩展到你关心的专题方向。

## 选择边界

- 教程路径较长，建议按阶段目标学习而非一次性通读。
- 章节实践仍需结合你的本地环境和算力条件。
- 生产级工程能力还需搭配评测和运维体系。
