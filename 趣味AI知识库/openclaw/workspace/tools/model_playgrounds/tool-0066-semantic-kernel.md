# 工具定位

Semantic Kernel 是企业导向的 AI 编排 SDK，适合构建跨模型、跨语言、可治理的 Agent 与流程系统。

## 适用场景

- 你要在企业内统一多模型和多代理编排能力
- 你要把业务函数、API 和工具插件化接入代理系统
- 你要在 Python/.NET/Java 团队之间保持架构一致

## 核心能力

- 模型无关接入: 支持多模型与本地部署选项
- 插件与流程框架: 结构化组织复杂业务流程
- 多代理协作: 支持专业代理分工与组合执行

## 上手路径

1. 先从单代理 + 插件调用跑通最小链路。
2. 再加入多代理协作和流程编排。
3. 最后接入观测、权限和运维策略进入生产。

## 选择边界

- 体系完整但学习成本较高，适合中大型团队。
- 需要工程规范配套才能发挥企业级优势。
- 若仅做轻量原型，框架能力可能过重。
