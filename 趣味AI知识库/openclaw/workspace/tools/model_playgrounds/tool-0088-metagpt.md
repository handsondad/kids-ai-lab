# 工具定位

MetaGPT 是角色化多代理框架，适合把软件团队流程映射为可执行代理协作链路。

## 适用场景

- 你要验证多角色代理协同开发模式
- 你要从自然语言需求快速生成项目雏形
- 你要把 SOP 流程固化为代理执行规范

## 核心能力

- 角色协作模型: PM/架构/开发等职责分工
- 需求到仓库链路: 一行需求驱动产物生成
- 双形态使用: CLI 快速试验与库模式集成

## 上手路径

1. 先用 CLI 跑通最小需求生成样例。
2. 再按业务场景调整角色与流程配置。
3. 最后将关键 SOP 模块化并可复用。

## 选择边界

- 长链协作对成本与模型稳定性要求较高。
- 生成结果需要人工架构与代码审查。
- 多角色流程设计复杂，需循序渐进引入。
