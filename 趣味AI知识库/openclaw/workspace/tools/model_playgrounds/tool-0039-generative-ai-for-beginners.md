# 工具定位

Generative AI for Beginners 是体系化入门课程工具，适合把零散学习改造成连续可执行的 21 课路径。

## 适用场景

- 你要从入门到应用构建建立完整学习路线
- 你要给团队新人制定统一学习大纲
- 你要按周推进提示、RAG、Agent 等核心主题

## 核心能力

- 课程结构清晰: Learn 与 Build 双轨并行
- 主题覆盖全: 从基础到安全、生命周期与微调
- 代码配套: 支持快速练习与二次改造

## 上手路径

1. 先按 00-05 课建立概念和提示基础。
2. 再做 06-11 的构建课形成实操能力。
3. 最后完成 12+ 课题，补齐安全、RAG、Agent 与微调。

## 选择边界

- 课程偏广度，深度场景需要补官方文档和实践。
- 个别教程依赖可能随版本变化。
- 需要基础编程能力配合实践。
