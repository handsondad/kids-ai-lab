# 工具定位

Awesome Machine Learning 是面向机器学习生态的高密度资源导航清单，适合快速建立“按语言和任务找资源”的检索能力。

## 适用场景

- 你要在某个技术栈中快速找到可用 ML 框架与工具
- 你要补课程、书籍、活动等学习资源索引
- 你要做方案调研并快速形成候选工具列表

## 核心能力

- 多语言导航: 按语言聚合框架与工具，便于技术栈对齐
- 资源外延广: 同时覆盖课程、书籍、博客和社区活动
- 社区维护: 持续更新并标记部分弃用资源

## 上手路径

1. 先按你的主力语言定位框架与工具候选。
2. 再结合任务类型筛选最相关的 3-5 个条目。
3. 最后回到官方仓库验证维护状态与适配成本。

## 选择边界

- 清单本身不提供统一质量评测，需要二次验证。
- 条目很多，初学者需要先限定范围再深入。
- 对快速演进领域，历史条目可能存在时效偏差。
