# Language Models

## Introduction

Language Models is a Python package that exposes a simple API for local LLM use with low memory requirements.

## Key Features

- Minimal API for instruction following, completion, retrieval helpers, and semantic search.
- Configurable RAM-based model selection for different hardware constraints.
- Quantization-oriented CPU runtime with optional GPU acceleration.
- Practical examples for learners and lightweight application prototypes.

## Getting Started

Install `languagemodels`, import as `lm`, and call simple methods such as `lm.do()` and `lm.complete()` to run local tasks.
