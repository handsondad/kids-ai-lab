# 工具定位

LLM Course 是一个以路线图组织的 LLM 全链路学习仓库，适合希望同时掌握模型训练与应用工程的人。

## 适用场景

- 你想要一张完整的 LLM 学习地图避免盲目跳转
- 你需要同时补齐 Scientist 与 Engineer 两条能力线
- 你希望围绕 RAG、Agent、部署、安全建立实战框架

## 核心能力

- 双轨路线: 模型构建与系统工程并行学习
- 主题分层: 预训练、SFT、对齐、评测、部署等结构清晰
- 延伸索引: 每章都给出可追踪的参考资源

## 上手路径

1. 先浏览完整 roadmap，标注你当前能力缺口。
2. 再按 Scientist 或 Engineer 先深挖一条主线。
3. 最后将两条主线在 RAG/Agent/部署项目中合并验证。

## 选择边界

- 路线图提供方向，不替代具体工程实现细节。
- 部分高级章节对数学、分布式训练与工程经验有门槛。
- 建议配套真实项目，否则容易停留在“看懂但不会做”。
