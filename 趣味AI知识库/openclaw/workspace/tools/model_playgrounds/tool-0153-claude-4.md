# 工具定位

Claude 4是Anthropic发布的大语言模型，以编程能力登顶著称，在SWE-bench上达到80.8%榜首，擅长企业级代码开发、法律学术等严肃任务。

## 适用场景

- 企业级代码开发和审查
- 法律、学术等严肃任务
- 安全敏感的企业应用
- 长文本处理（100万Token）

## 核心能力

- **编程能力**: SWE-bench 80.8%榜首
- **宪法AI**: 遵循无害、诚实、有益、可解释准则
- **长文本稳定**: 处理百万级Token不漂移
- **代码质量**: 工程级代码生成，直接可用

## 上手路径

1. 先通过Claude.ai体验对话和代码生成能力。
2. 尝试处理长文档，验证稳定性。
3. 引入到企业开发流程，进行代码审查和生成。

## 选择边界

- 定价最高：输入$5/M tokens，输出$25/M tokens
- 安全对齐严格，可能拒绝某些任务
- 不适合需要灵活性的创意任务
