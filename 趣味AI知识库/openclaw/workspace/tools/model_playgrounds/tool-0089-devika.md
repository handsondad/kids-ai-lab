# 工具定位

Devika 是开源 Agentic Software Engineer 实验项目，适合探索“任务分解 + 检索 + 编码”的自治开发流程。

## 适用场景

- 你要实验高层目标到代码产出的代理闭环
- 你要观察代理任务状态与执行过程
- 你要评估不同模型下的自治开发能力

## 核心能力

- 目标分解: 将高层任务拆成可执行步骤
- 研究与编码联动: 结合检索与代码生成
- 项目视图管理: 提供状态追踪与交互界面

## 上手路径

1. 先按官方最小安装跑通基础任务。
2. 再配置模型与搜索能力做效果对比。
3. 最后在受控任务上评估稳定性与成本。

## 选择边界

- 项目处于早期阶段，稳定性存在波动。
- 生产级使用前需补齐安全与审计能力。
- 复杂任务需人工验收与分阶段回滚。
