# 工具定位

DuMate 是一款强调“情感连接”与“任务协作”并重的 AI 伙伴工具。它常被用作 OpenClaw 的前端交互层，提供更加友好、人性化的对话体验。

## 适用场景

- **创意头脑风暴**：与用户进行多轮启发式对话。
- **个人生活管理**：作为私人助理提醒生活琐事，具备比普通机器人更温和的语气。

## 核心能力

- **个性化人格模板**：用户可以根据喜好定制其性格，使其更像一位“同事”或“朋友”。
- **跨平台记忆同步**：在不同设备上保持一致的对话状态和偏好记忆。

## 上手路径

1. **注册账号**：访问 DuMate 平台。
2. **连接 OpenClaw**（可选）：将其作为 OpenClaw 的高级 UI 层，获取操作系统的执行能力。

## 选择边界

- **深度工程能力**：相比 Trae-Solo 或标准版 OpenClaw，其更偏向交互而非底层的重度工程操作。
