# 工具定位

DeepSeek-R1是深度求索发布的开源大语言模型，以推理能力强、开源免费著称，在Chatbot Arena榜单中以1398 ELO分数排名第三，适合科研、成本敏感应用和国产化替代。

## 适用场景

- 科研和学术研究
- 成本敏感的应用
- 国产化替代需求
- 数学、科学推理任务

## 核心能力

- **推理能力强**: 数学、科学推理表现优异
- **开源免费**: MIT协议，完全开源
- **性价比高**: 输入$0.55/M tokens，输出$2.19/M tokens
- **国产适配**: 全面适配国产算力
- **稀疏注意力**: NSA架构，提升推理效率

## 上手路径

1. 先通过DeepSeek官网或API体验基础能力。
2. 尝试数学和科学推理任务，验证推理质量。
3. 部署到本地或国产算力平台，实现自主可控。

## 选择边界

- 社区生态相对较小
- 工具链和文档不如闭源模型完善
- 某些复杂任务可能不如GPT-5和Claude 4
- 需要一定的技术能力来部署和优化
