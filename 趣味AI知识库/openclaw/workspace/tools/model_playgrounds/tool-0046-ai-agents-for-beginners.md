# 工具定位

AI Agents for Beginners 是面向初学者到进阶学习者的 Agent 系统化课程仓库，适合作为 Agent 工程学习主线。

## 适用场景

- 你需要一条从概念到实操的 Agent 学习路线
- 你希望按专题系统掌握设计模式、RAG、多 Agent 与协议
- 你想给团队建立统一的 Agent 学习基线

## 核心能力

- 课程化章节编排: 覆盖基础、模式、生产与协议
- 每课配套代码样例: 降低学习到实践转换成本
- 多语言支持: 便于跨语言团队同步学习

## 上手路径

1. 先按课程顺序通读基础章节并跑通样例。
2. 再针对工具使用、RAG、多 Agent 章节做小项目练习。
3. 最后结合生产与协议章节形成你的工程落地清单。

## 选择边界

- 它是学习资源，不直接替代生产框架与平台。
- 课程中的生态偏好较明显，建议配合其他框架交叉验证。
- 高级部署与治理仍需要额外工程实践。
