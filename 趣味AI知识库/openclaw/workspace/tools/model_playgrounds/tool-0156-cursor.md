# 工具定位

Cursor是Anysphere开发的AI原生IDE，以用户体验最佳著称，支持多Agent并行工作，SWE-bench约73%，适合全栈开发、快速原型开发和团队协作。

## 适用场景

- 全栈开发
- 快速原型开发
- 团队协作项目
- 需要可视化编辑的开发者

## 核心能力

- **用户体验最佳**: Glass界面流畅
- **多Agent并行**: 最多8个Agent同时工作
- **可视化编辑**: IDE级别体验
- **Composer 2.0**: 跨文件编辑和重构
- **Tab补全**: 智能预测整个修改块
- **云端执行**: 不占本地资源

## 上手路径

1. 下载并安装Cursor IDE。
2. 打开一个项目，体验代码补全和编辑能力。
3. 尝试Composer功能，进行跨文件重构。
4. 引入到团队协作流程。

## 选择边界

- Pro版$20/月，Business版$40/月
- 免费版每日50次调用，限制较多
- 需要网络连接
- 不适合离线开发场景
