# 工具定位

OpenBB 是面向分析与代理场景的数据平台，用统一后端把金融数据能力分发到 Python、API、Workspace 等多个消费面。

## 适用场景

- 你要把研究数据同时供给脚本分析和 AI 代理
- 你希望减少多团队重复接入同类数据源
- 你要构建可复用的数据后端并快速接到应用前端

## 核心能力

- 多终端复用: connect once, consume everywhere
- Python 与 API 双通道: 既可探索也可服务化
- 代理友好: 可作为智能体工具调用的数据底座

## 上手路径

1. 先本地安装并跑通最小查询样例。
2. 再启动 API 服务并验证端到端数据可用性。
3. 最后接入你的分析面板或代理流程。

## 选择边界

- 数据合规和许可边界要按具体数据源核验。
- 金融场景需设置审计、回溯和风控机制。
- 并非投资建议系统，输出需要专业复核。
