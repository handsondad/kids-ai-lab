# MLflow

## Introduction

MLflow provides end-to-end workflows for ML and GenAI systems, from experiment tracking to monitoring and deployment.

## Key Features

- Run tracking, artifact logging, and registry workflows.
- LLM/agent tracing and evaluation capabilities.
- Prompt and gateway-oriented governance features.
- Broad integrations with providers and agent frameworks.

## Getting Started

Run an MLflow server, connect clients via tracking URI, and enable instrumentation to collect traces, metrics, and artifacts in a shared UI.
