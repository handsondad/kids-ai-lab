# OpenDevin

## Introduction

OpenDevin is an open-source project that aims to replicate, innovate, and push the boundaries of autonomous AI software engineers. Inspired by Cognition AI's Devin, OpenDevin provides a framework for building and evaluating AI agents that can perform complex software engineering tasks.

## Key Features

*   **Extensible Agent Framework:** OpenDevin provides a flexible and extensible framework for building various types of AI agents.
*   **Sandbox Environment:** The project includes a sandboxed Docker environment to ensure safe execution of agent-generated code.
*   **Evaluation Harness:** OpenDevin comes with an evaluation harness for testing the performance of agents on different software engineering tasks.
*   **Frontend and Backend:** The project includes a React-based frontend for interacting with the agent and a Python backend powered by FastAPI.

## Getting Started

To get started with OpenDevin, you can clone the repository and follow the setup instructions in the documentation. The project can be run locally using Docker Compose.
