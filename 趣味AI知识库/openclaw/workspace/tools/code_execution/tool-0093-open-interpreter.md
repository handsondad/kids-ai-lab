# Open Interpreter

## Introduction

Open Interpreter is an open-source project that lets LLMs run code (Python, Javascript, Shell, and more) locally. It provides a natural-language interface to your computer's general-purpose capabilities, allowing you to perform a wide range of tasks by chatting with the interpreter in your terminal.

## Key Features

*   **Local Code Execution:** Open Interpreter runs code in your local environment, giving it full access to the internet, unrestricted file sizes, and the ability to use any package or library.
*   **Interactive Chat Interface:** You can interact with Open Interpreter through a ChatGPT-like interface in your terminal.
*   **Broad Capabilities:** It can be used to create and edit photos, videos, PDFs, control a Chrome browser for research, analyze large datasets, and more.
*   **Safety Confirmation:** By default, Open Interpreter asks for user confirmation before executing code to prevent unintended actions.
*   **Customizable:** You can customize the system message, change the language model, and configure the interpreter using YAML files.
*   **Local Model Support:** It can connect to local language models running on your machine via servers like LM Studio.

## Getting Started

Open Interpreter can be installed via pip. After installation, you can start the interactive chat by running `interpreter` in your terminal. It can also be used as a Python library in your own projects.
