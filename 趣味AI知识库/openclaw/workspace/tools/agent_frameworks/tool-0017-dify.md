# 工具定位

Dify 是面向生产场景的 LLM/Agent 应用开发平台，用可视化编排和平台治理能力把 Prompt、RAG、Agent、监控和 API 集成到一套工作流中。

## 适用场景

- 你希望团队快速搭建并迭代 Agent/RAG 应用
- 你需要在同一平台管理模型接入、工作流和应用发布
- 你要把原型能力通过 API 嵌入业务系统并持续观测

## 核心能力

- 可视化编排: 工作流、Prompt、RAG、Agent 在同一界面协同
- 平台治理: 支持模型管理、日志分析和持续优化闭环
- 部署灵活: 云端试用与自托管落地均可支持

## 上手路径

1. 先搭一个最小工作流应用并验证业务价值。
2. 再接入知识库与模型路由，补齐评测和日志观测。
3. 最后通过 API 接入业务系统，形成稳定迭代发布流程。

## 选择边界

- 平台能力越全，治理和运维复杂度也越高。
- 可视化效率高，但核心策略仍需工程化评测验证。
- 企业部署需提前规划权限、合规与资源成本。
