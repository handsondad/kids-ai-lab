# Marvin

## Introduction

Marvin is a Python framework for building agentic workflows with strong structured-output support.

## Key Features

- `marvin.run` for simple task execution.
- `marvin.Task` and `marvin.Agent` abstractions for orchestrated workflows.
- Type-safe output patterns for production pipelines.
- Thread-based context sharing across multi-step tasks.

## Getting Started

Install from PyPI and begin with high-level helpers, then evolve to explicit task/agent orchestration as complexity grows.
