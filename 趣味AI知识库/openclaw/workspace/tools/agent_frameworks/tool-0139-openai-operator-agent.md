# 工具定位

OpenAI Operator 是 OpenAI 官方推出的自主网页智能体。它能够通过浏览器界面直接与数字世界交互，代表用户执行多步骤、跨网站的任务。

## 适用场景

- **端到端网页操作**：如“在 LinkedIn 上找到 10 个 AI 工程师并整理到 Google Sheets”。
- **复杂事务代办**：自动处理表单填写、预订和数据同步。
- **个人数字代理**：在用户离线时持续执行后台任务。

## 核心能力

- **Computer Use (Web)**：模拟人类在浏览器中的点击、滚动和输入行为。
- **推理与纠错**：遇到弹窗或验证码时，能尝试自主绕过或提示用户介入。
- **多步目标维持**：在长达数十分钟的网页操作中保持对核心目标的追踪。

## 上手路径

1. **ChatGPT Pro/Plus**：通过 ChatGPT 界面顶部的“Operator”开关启用。
2. **Operator 独立客户端**：使用 OpenAI 提供的专用浏览器环境。
