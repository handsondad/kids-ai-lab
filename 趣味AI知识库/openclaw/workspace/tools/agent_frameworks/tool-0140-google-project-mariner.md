# 工具定位

Project Mariner 是 Google 开发的基于 Gemini 2.0 原生能力的自主网页智能体。它通过一个实验性的 Chrome 扩展程序，能够直接理解并操作浏览器中的像素和网页元素。

## 适用场景

- **跨页面复杂研究**：在 WebVoyager 等基准测试中表现卓越，能自主跨越多个页面搜集并整合信息。
- **UI 自动化交互**：直接理解文本、代码、图像和表单，代用户完成繁琐的网页操作。

## 核心能力

- **屏幕像素理解**：利用 Gemini 2.0 的原生多模态能力，直接“看”浏览器屏幕进行决策。
- **与 Chrome 深度整合**：作为官方原型，其对网页元素的定位和操作比第三方插件更精准。
- **智能体时代基石**：是 Google 展示其“Agentic Era”愿景的核心产品之一。

## 上手路径

1. **开发者预览**：目前通过 Google AI Studio 或特定的 Chrome 实验性版本开放。
2. **Side Panel**：在 Chrome 侧边栏分配任务并观察其执行。
