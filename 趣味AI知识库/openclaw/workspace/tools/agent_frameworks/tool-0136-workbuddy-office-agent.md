# 工具定位

WorkBuddy 是一款基于 OpenClaw 架构深度定制的办公场景智能体，旨在通过极简的聊天界面，帮助职业人士处理繁杂的日常行政、沟通和协调工作。

## 适用场景

- **邮件分级与草拟**：自动过滤垃圾邮件，并根据紧急程度草拟回复建议。
- **跨平台日程同步**：在微信/Telegram 中通过一句话将会议同步到 Outlook 和 Google Calendar。
- **周报自动生成**：根据本周的 Git 提交记录、Slack 聊天摘要自动生成工作周报草稿。

## 核心能力

- **预置办公技能包**：相比通用版 OpenClaw，它预装了大量针对常用办公软件（Notion, Zoom, Jira）的优化技能。
- **极简对话界面**：无需了解底层逻辑，所有操作通过“人话”指令完成。

## 上手路径

1. **绑定账户**：在 WorkBuddy 后台绑定你的办公邮箱和协作平台账号。
2. **设置偏好**：告知它你的工作时间和处理邮件的习惯。
3. **开始会话**：通过 Slack 或企业微信添加 WorkBuddy 机器人开始工作。

## 选择边界

- **数据隐私**：在企业环境使用时，需确保符合公司的安全审计要求，建议使用私有部署版本。
