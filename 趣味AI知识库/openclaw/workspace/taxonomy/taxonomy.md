# Taxonomy

Use the following controlled vocabulary whenever possible.
If a new tag is needed, add it here first before using it widely.

## Learning Levels

- `level_000`: complete beginner, orientation level
- `level_100`: basic concepts and vocabulary
- `level_200`: can explain core mechanisms and tradeoffs
- `level_300`: can design workflows or systems
- `level_400`: can evaluate, optimize, and critique production practice
