# 专题说明

这个合集面向已经有基础部署经验、希望系统掌握大模型原理与工程实践的学习者。

## 推荐顺序

1. 先看 `topic-0046`，建立理论到实战的三段式主线。
2. 再看 `tool-0127`，把 happy-llm-main 作为章节化课程地图。
3. 再看 `topic-0047`，完成从手写 LLaMA2 到框架训练迁移。
4. 再看 `topic-0048`，补齐 Eval-RAG-Agent 应用层闭环。
5. 再看 `topic-0049`，建立小模型微调的成本与隐私决策方法。
6. 再看 `topic-0050`，掌握解码策略对输出质量的控制方法。
7. 再看 `topic-0051`，把 thinking budget 纳入推理优化策略。
8. 再看 `topic-0052`，学习多模态拼接微调的快速验证路径。
9. 再看 `topic-0053`，掌握专业文档场景的知识引导 RAG。
10. 再看 `topic-0054`，掌握 Tiny-LLM 预训练/SFT 训练循环模板。
11. 再看 `topic-0055`，掌握 tokenizer 与 loss mask 数据对齐流程。
12. 再看 `topic-0056`，完成 Transformers + DeepSpeed 训练迁移。
13. 再看 `topic-0057`，跑通最小 RAG 文档问答闭环。
14. 再看 `topic-0058`，搭建函数调用 Agent 的最小可用框架。
15. 再看 `topic-0059`，将 Agent 最小框架转成可演示 Web 应用。
16. 再看 `topic-0060`，按 notebook 复现实验单做端到端走查。
17. 再看 `topic-0061`，按章节-脚本-产物矩阵推进复现与验收。
18. 再看 `topic-0062`，对 RAG 做上线前风险走查与加固。
19. 再看 `topic-0063`，对 Agent 做工具执行安全与审计治理。
20. 再看 `topic-0064`，补齐训练前文本数据处理基础能力。
21. 再看 `topic-0065`，从源码角度建立 Transformer 结构认知。
22. 再看 `topic-0066`，用最小代码模板做结构改造演练。
23. 再看 `tool-0031`，对照课程化资源做延展阅读。
24. 再看 `tool-0103`，巩固高效微调方法在训练管线中的位置。
25. 最后看 `tool-0111`，连接到生产级推理服务化路径。

## 使用建议

- 每章至少完成一次代码复现并记录关键参数。
- 训练实验先保证可复现，再优化速度和成本。
- 应用阶段先建立评测基线，再推进 RAG 与 Agent。
