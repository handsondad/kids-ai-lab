# 专题说明

该合集将 LLM Course README 的链接资产按学习和工程阶段重排，方便你在知识库内直接检索与执行。

## 推荐顺序

1. 先看 `topic-0082`，补齐基础知识与课程预备能力。
2. 再看 `topic-0085`，先跑 Notebook 建立动手直觉。
3. 再看 `topic-0086`，先用链接内容索引定位每个链接的用途。
4. 再看 `topic-0087`，按 30 天计划组织每周学习与产出。
5. 再看 `topic-0083`，进入 Scientist 训练与评测提升路径。
6. 再看 `topic-0084`，进入 Engineer 生产化与安全路径。
7. 最后看 `note-0013`、`article-0142` 与 `article-0143`，做全量链接回溯。

## 包含卡片

- `topic-0082`: LLM 基础资源导航图。
- `topic-0083`: LLM Scientist 资源地图。
- `topic-0084`: LLM Engineer 资源地图。
- `topic-0085`: LLM Course Notebook 实操路径。
- `topic-0086`: LLM Course 链接内容索引。
- `topic-0087`: LLM Course 30 天执行计划。
- `note-0013`: README 链接提炼笔记。
- `article-0142`: README 链接分组清单来源。
- `article-0143`: README 外链内容逐链接摘要来源。

## 使用建议

- 以周为单位推进，每周固定“1 个基础主题 + 1 个实操复现”。
- 每轮学习结束后，把新增结论回写为自己的短卡。
