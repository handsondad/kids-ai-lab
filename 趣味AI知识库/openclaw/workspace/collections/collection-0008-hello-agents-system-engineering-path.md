# 专题说明

这个合集面向希望构建真实多智能体系统的开发者，强调从框架设计到训练评测再到应用交付的完整工程路径。

## 推荐顺序

1. 先看 `topic-0067`，建立从基础到交付的全局地图。
2. 再看 `tool-0128`，将 hello-agents-main 作为课程与代码总入口。
3. 再看 `topic-0068`，掌握从零搭建 Agent 框架的方法。
4. 再看 `topic-0069`，完成记忆、检索、上下文的融合设计。
5. 再看 `topic-0070`，掌握 MCP/A2A/ANP 协议选型和接入。
6. 再看 `topic-0071`，建立训练和评测驱动的优化闭环。
7. 再看 `topic-0072`，将能力模块拼装为可交付应用。
8. 再看 `topic-0073`，掌握协议层的工程化接入模板。
9. 再看 `topic-0074`，跑通 Agentic-RL 训练流水线模板。
10. 再看 `topic-0075`，掌握评测自动化与结果归档流程。
11. 再看 `topic-0076`，复现多智能体旅行助手工程模板。
12. 再看 `topic-0077`，复现深度研究智能体编排模板。
13. 再看 `topic-0078`，掌握 Skills 与 MCP 的分层协作方法。
14. 再看 `topic-0079`，掌握 Code Agent 可诊断优先设计。
15. 再看 `topic-0080`，按共创规范完成项目交付。
16. 再看 `topic-0081`，完成 Node.js/npx 与 n8n 环境引导。
17. 再看 `tool-0046`，补齐 Agent 框架体系化实践视角。
18. 再看 `tool-0103`，补齐训练优化与成本控制视角。
19. 最后看 `tool-0111`，连接到服务化部署与工程运维。
