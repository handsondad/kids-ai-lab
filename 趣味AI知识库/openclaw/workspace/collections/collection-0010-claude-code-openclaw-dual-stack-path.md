# 专题说明

这个合集用于把 Claude Code 与 OpenClaw 串成一条可执行的双栈工程路径，兼顾开发效率与运行治理。

## 推荐顺序

1. 先看 `topic-0088`，建立 Claude Code 自动化系统观。
2. 再看 `topic-0089`，跑通 OpenClaw 安装与模型路由。
3. 再看 `topic-0090`，补齐技能、记忆与安全治理。
4. 再看 `topic-0091`，把双栈组织为团队可执行路线。
5. 再看 `topic-0092`，明确官方与社区能力边界。
6. 再看 `topic-0093`，完成生产加固清单。
7. 再看 `topic-0094`，按 14 天计划推进上线。
8. 最后看 `note-0014`、`article-0144`、`note-0015` 与 `article-0145` 做来源回溯。

## 包含卡片

- `topic-0088`: Claude Code 自动化系统手册。
- `topic-0089`: OpenClaw 部署与模型路由手册。
- `topic-0090`: OpenClaw 技能记忆安全治理手册。
- `topic-0091`: Claude 与 OpenClaw 双栈路线图。
- `topic-0092`: Claude 与 OpenClaw 能力边界治理。
- `topic-0093`: OpenClaw 生产加固检查清单。
- `topic-0094`: Claude 与 OpenClaw 14天落地计划。
- `note-0014`: 双栈提炼笔记。
- `article-0144`: 仓库总览来源卡。
- `note-0015`: 深度执行提炼笔记。
- `article-0145`: 优先级与执行来源卡。

## 使用建议

- 先完成最小可运行，再做多能力叠加。
- 每一步都记录可验证产出与风险控制项。
