# GPT-5发布

## 事件概述

OpenAI于2026年1月15日正式发布GPT-5，推理能力达到1428 ELO，成为全球最强推理模型，标志着大语言模型进入新阶段。

## 关键信息

### 发布时间
- 发布日期: 2026年1月15日
- 发布方: OpenAI

### 核心能力
- **推理能力**: 1428 ELO，全球最强
- **上下文窗口**: 超长上下文支持
- **多模态**: 文本+图像支持
- **应用场景**: 复杂推理、科学研究、专业应用

### 市场影响
- 确立OpenAI在推理能力上的领先地位
- 推动AI应用向复杂推理场景扩展
- 与Claude 4、Gemini 3形成"四强争霸"格局
