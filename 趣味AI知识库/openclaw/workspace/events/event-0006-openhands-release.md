# 事件概览

2024年6月，All-Hands-AI 发布 OpenHands，这是一个AI驱动的软件开发平台，提供自主编码智能体，在 SWE-Bench Verified 上达到 72% 准确率，标志着AI辅助软件开发进入实用阶段。

## 关键变化

- **自主编码**: 智能体能够编辑文件、运行命令、浏览网页
- **高准确率**: SWE-Bench Verified 72%，接近人类开发者水平
- **沙盒环境**: 提供安全的代码执行环境
- **多模型支持**: 支持Claude、OpenAI、MiniMax等多种LLM

## 为什么重要

- **生产力革命**: 大幅提升软件开发效率
- **质量保证**: 在标准基准上达到高准确率
- **降低门槛**: 让更多人能够进行软件开发
- **推动发展**: 激励更多AI编程工具的开发

## 后续影响

- **工具生态**: 推动Aider、SWE-agent等工具的发展
- **应用扩展**: 从Bug修复扩展到代码重构、测试生成
- **开发范式**: 改变软件开发的工作方式，成为开发者的常用工具
- **研究基础**: 成为AI科研自动化系统的执行引擎
