# Sora关停

## 事件概述

OpenAI于2026年3月24日正式关停Sora视频生成服务，原因是日均亏损100万美元、用户留存率低（30天留存率仅1%）、算力成本过高、竞争力被中国厂商超越。

## 关键信息

### 关停时间
- 关停日期: 2026年3月24日
- 关停方: OpenAI

### 关停原因
- **日均亏损**: 100万美元
- **用户留存率低**: 30天留存率仅1%，60天归零
- **算力成本过高**: 视频生成成本难以覆盖
- **竞争力被超越**: 中国厂商（SeeDance 2.0、可灵3.0）技术领先

### 技术贡献
- **时空补丁**: Spacetime Patches技术
- **扩散Transformer**: DiT架构
- **世界模型雏形**: 为后续研究奠定基础

## 市场影响

### 对视频生成市场的影响
- 中国视频生成工具确立领先地位
- 视频生成市场格局重塑
- 算力成本成为关键制约因素

### 对竞争格局的影响
- 中国AI在视频生成领域超越美国
- OpenAI退出视频生成市场
- 字节跳动、快手等中国厂商占据主导地位

## 教训与启示

### 商业模式可持续性
- 技术领先不等于商业成功
- 成本控制至关重要
- 用户留存率决定产品生死

### 竞争格局变化
- 中国AI在特定领域可以超越美国
- 技术创新需要商业支撑
- 市场竞争激烈，不进则退
