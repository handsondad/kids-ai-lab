# 一句话定义

SpatialLM 实操手册聚焦 3D 点云理解与目标检测任务，是从语言模型向空间智能扩展的关键能力卡。

## 典型链路

1. 搭建 SpatialLM 基础部署环境。
2. 跑通点云输入到任务输出链路。
3. 验证 3D 理解与检测效果。
4. 结合业务场景做数据与指标对齐。

## 实操要点

- 3D 数据预处理和标注质量是效果上限关键。
- 与 2D 视觉任务评测维度不同，需单独定义。
- 部署时需关注显存占用与推理稳定性。
