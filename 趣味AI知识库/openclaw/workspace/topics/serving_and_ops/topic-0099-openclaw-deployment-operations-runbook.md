# 一句话定义

这张卡沉淀 OpenClaw 从安装到稳定运维的全链路执行手册。

## 运维节奏

1. 启动链路：install -> onboard -> doctor。
2. 运行链路：gateway 健康检查与日志巡检。
3. 模型链路：主备模型与故障切换验证。
4. 升级链路：稳定线优先，预发布按需灰度。
