# 一句话定义

智能体系统学习路线图用于把 hello-agents 的 1 到 16 章拆成可执行的分阶段成长路径。

## 关键路径

1. 先完成基础层（chapter1-3）：建立 Agent 与 LLM 共识。
2. 再完成构建层（chapter4-7）：掌握范式、框架和自建能力。
3. 再完成增强层（chapter8-12）：补齐记忆、上下文、协议、训练、评测。
4. 最后完成交付层（chapter13-16）：在真实案例中形成系统化工程能力。

## 实操要点

- 每个阶段都应有对应代码复现和产出物。
- 学习顺序不建议跳章，chapter7-12 依赖明显。
- 以“可运行 + 可解释 + 可评测”作为阶段验收标准。

## 检索提示

- 适用于希望系统入门并最终落地多智能体项目的学习者。
