# 一句话定义

这张卡把 OpenClaw 的技能编排、记忆体系与安全机制打通成一体化治理框架。

## 治理框架

1. 能力层：Skills 负责流程编排，Tools 负责原子执行。
2. 记忆层：会话记忆 + 每日日志 + 长期记忆三层协同。
3. 安全层：API Key 管理、DM 配对、沙箱隔离、审计监控。

## 操作原则

- 技能优先解决“任务流程”，工具优先解决“单点动作”。
- 记忆内容保持可编辑、可回滚、可压缩，防止上下文污染。
- 对公网和团队场景，安全配置必须先于功能扩展。
