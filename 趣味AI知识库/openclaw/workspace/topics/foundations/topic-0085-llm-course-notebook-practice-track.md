# 一句话定义

这张卡聚焦 README 的 Colab 与配套文章，提供可直接执行的 Notebook 实操主线。

## 实操分组

1. 工具组：AutoEval、AutoQuant、AutoDedup 等一键工具实践。
2. 微调组：Unsloth、ORPO、DPO、QLoRA、Axolotl 训练路径。
3. 量化组：GPTQ、GGUF、EXL2 的模型压缩与部署前准备。
4. Other 组：MergeKit、Abliteration、Knowledge Graph、Decoding 进阶。

## 建议节奏

- 每次只跑一个 Notebook，并记录输入、参数、输出与结论。
- 对同任务至少对比两条方法路径（如 QLoRA vs DPO）。
- 复现成功后沉淀为自己的模板脚本或流程卡。
