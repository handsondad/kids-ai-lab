# 一句话定义

LLM 理论到实战进阶路线是一条从 NLP/Transformer 基础到模型训练与应用开发的系统学习路径。

## 三段式主线

1. 理论层：NLP、Transformer、预训练模型与 LLM 训练范式。
2. 训练层：从零实现小模型，再迁移到 Transformers 工业训练流程。
3. 应用层：建立 Eval、RAG、Agent 三位一体的应用认知。

## 为什么重要

- 能把“会调用模型”升级为“理解并可重构模型系统”。
- 学习成本更可控，章节之间依赖关系明确。
- 适合作为团队培养初中级 LLM 工程师的课程骨架。

## 实操要点

- 每一层至少完成一个可运行产物再进入下一层。
- 理论学习必须配合最小代码复现，避免只读不做。
- 训练层与应用层建议并行保留实验记录和问题清单。

## 检索提示

- 适用于 self-llm 后续进阶、希望系统补齐 LLM 原理和工程能力的学习场景。
