# 一句话定义

这张卡把 README 中的大量外链内容转为可检索的知识索引，便于按问题直接定位到合适链接。

## 索引结构

1. 入口层：作者动态、博客、DeepWiki、手册。
2. 实操层：Notebooks 工具组、微调组、量化组、Other 组。
3. 理论层：Fundamentals 与 Scientist。
4. 工程层：Engineer 的运行、RAG、Agent、部署、安全。

## 使用方式

- 当问题是入门补课：先查 Fundamentals 子索引。
- 当问题是训练提效：先查 Scientist 子索引。
- 当问题是应用落地：先查 Engineer 子索引。
- 当问题是动手复现：直接查 Notebooks 子索引。
