# 一句话定义

这张卡把 LLM Fundamentals 的数学、Python、神经网络、NLP 参考链接整理成可执行学习顺序。

## 推荐学习顺序

1. 数学四件套：线代、微积分、概率统计、直觉化可视课程。
2. Python 与机器学习基础：语法、数据处理、经典算法与降维。
3. 神经网络核心：结构、训练、优化、过拟合治理。
4. NLP 基础：预处理、表示学习、RNN/LSTM/GRU。

## 链接使用建议

- 每个主题至少搭配 1 个视频和 1 个可动手资源。
- 看完资源后，把核心概念写成 5 条自己的检索问句。
- 优先把“可复现代码/练习”打通，再进入 Scientist 章节。

## 检索提示

- 对应 LLM Course 的 Fundamentals 区域，适合入门补课和查漏补缺。
