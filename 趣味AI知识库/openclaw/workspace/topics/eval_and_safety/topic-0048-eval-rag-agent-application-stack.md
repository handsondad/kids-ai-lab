# 一句话定义

Eval-RAG-Agent 应用栈入门是一条把模型能力转化为真实应用的最小方法链：先评测、再检索增强、再智能体编排。

## 关键路径

1. 先理解评测：数据集、榜单、指标与风险。
2. 再搭 Tiny-RAG：文档切分、向量化、检索、生成闭环。
3. 最后补 Agent：把工具调用和任务流程编排进系统。

## 为什么重要

- 能避免“只看 demo，不可上线”的常见问题。
- 帮助学习者建立应用层的完整因果链。
- 适合快速做业务 PoC 和能力验证。

## 实操要点

- 评测基线要先于 RAG 与 Agent 迭代。
- RAG 先关注召回质量，再优化生成质量。
- Agent 先做可控流程，再追求自治复杂度。
