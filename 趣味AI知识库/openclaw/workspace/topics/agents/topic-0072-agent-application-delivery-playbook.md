# 一句话定义

多智能体应用交付手册用于将 Agent 能力模块组合成完整产品，并覆盖从原型到上线的工程闭环。

## 关键路径

1. 采用前后端分离与服务分层架构组织系统。
2. 将任务拆解为多个专门 Agent 并定义协作接口。
3. 接入外部 API、工具与流式反馈机制形成可用产品体验。
4. 通过日志、评测与复盘机制持续优化交付质量。

## 实操要点

- 先明确最小可交付场景，再扩展多角色协作。
- 数据模型和状态流转需要优先设计，避免后期返工。
- 交付阶段需同时关注可用性、可解释性和可维护性。
