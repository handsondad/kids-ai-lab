# 一句话定义

AI科研自动化是指利用AI智能体自动化科学研究流程，从文献综述、想法生成、实验设计到论文撰写的端到端自动化。

## 为什么重要

- **加速科研周期**: 将研究周期从月缩短到天，大幅提升科研效率
- **降低研究门槛**: 让更多人能够开展高质量研究
- **标准化流程**: 将研究流程结构化，提高可复现性
- **释放人力**: 让研究者专注于创新性思考，而非重复性工作

## 关键机制

1. **文献综述自动化**: 自动检索、阅读、总结大量文献（STORM、GPT Researcher）
2. **想法生成与验证**: 基于文献自动生成研究假设并评估新颖性
3. **实验自动化**: 自动设计实验、编写代码、执行并分析结果（OpenHands、AIDE）
4. **论文撰写**: 基于实验结果自动生成论文草稿（AI-Scientist）
5. **多智能体协作**: 专业化智能体协同完成复杂研究任务

## 与相邻主题的关系

- **与 Agents 强相关**: 科研自动化是智能体技术的重要应用场景
- **与 RAG 相关**: 文献综述依赖检索增强生成技术
- **与 Code Automation 相关**: 实验自动化依赖代码生成能力
- **与 Multi-Agent Systems 相关**: 复杂研究任务需要多智能体协作

## 常见误区

- **误区1**: "AI能完全替代人类研究者"
  - 实际: AI是辅助工具，人类仍需提供创新性想法和最终判断

- **误区2**: "自动化研究质量不高"
  - 实际: AI-Scientist-v2生成的论文已通过同行评审，质量在特定领域已达标

- **误区3**: "只适合机器学习研究"
  - 实际: Biomni等工具已覆盖生物医学、InternAgent支持跨学科研究

## 下一步学习建议

- **先读**: AI-Scientist论文，理解端到端研究流程
- **先练**: 使用STORM生成一个主题的文献综述
- **再深入**: 学习OpenHands或AIDE的代码自动化能力
- **最后**: 尝试AI-Scientist完成一个小型研究项目
