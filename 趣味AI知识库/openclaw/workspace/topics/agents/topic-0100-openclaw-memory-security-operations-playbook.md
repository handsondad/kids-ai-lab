# 一句话定义

这张卡将 OpenClaw 的记忆管理与安全治理整合为日常可执行运维手册。

## 核心动作

1. 记忆治理：分层清理、去噪、保留关键事实。
2. 密钥治理：环境变量化与定期轮换。
3. 权限治理：DM pairing、allowlist、最小权限。
4. 审计治理：日志、异常告警、应急演练。
