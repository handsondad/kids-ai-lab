# 一句话定义

Agent 共创项目交付指南用于将个人或团队的智能体项目按照统一规范沉淀为可复用、可评审、可协作的开源成果。

## 关键路径

1. 按命名规范创建项目目录。
2. 按最小交付结构准备 README、依赖和主入口文件。
3. 在文档中明确功能、技术栈、运行方式和示例。
4. 通过 PR 流程提交并完成社区评审。

## 实操要点

- 项目文档质量直接影响复现与评审效率。
- 先保证最小可运行，再补优化与扩展特性。
- 建议附带失败经验和改进路线，提升学习价值。

## 检索提示

- 适用于毕业设计、社区共创和团队内部项目集建设。
