# Kids-AI-Lab

Kids-AI-Lab 是一个专为儿童设计的人工智能项目，旨在通过趣味和互动的方式，激发孩子们的创造力和学习兴趣，同时为家长和教育者提供科学、系统的育儿资源。知识都放在 `kb/` 下的六个 Markdown 知识库里，通过 [DeepSeek Harness（DSH）](dsh/README.md) 的插件和模式来查询、使用和扩充。

## 项目内容

```
kb/                 六个知识库（规范见 kb/README.md）
dsh/packages/       DSH 插件：dsh-kids-kb（知识库工具和「知识库模式」）、dsh-kids-lab（「实验模式」）
dsh/scripts/        把插件装进 DSH Profile 的脚本
AGENTS.md           给 AI Agent 的开发和扩充指南
```

### 知识库

| 目录 | 名称 | 内容 |
| --- | --- | --- |
| `kb/games` | 亲子游戏知识库 | 按年龄和发展领域分类的亲子互动游戏，帮助家长与孩子进行有效的互动 |
| `kb/language` | 语言发展知识库 | 按年龄阶段组织的语言发展理论和练习，支持儿童语言能力的发展 |
| `kb/psychology` | 儿童心理学知识库 | 儿童心理发展的阶段知识和情境支持，帮助家长理解孩子的心理需求 |
| `kb/wonder` | 孩子的奇妙视界 | 回答孩子关于世界和自我的“为什么”：给孩子怎么说、给爸爸怎么接 |
| `kb/ai` | 趣味AI知识库 | 人工智能主题、工具、事件和学习路线，激发孩子对科技的兴趣 |
| `kb/science` | 趣味科学实验库 | 适合儿童动手做的科学实验和科学主题，培养科学探究精神 |

每个库有 `library.json`（库的用途和卡片类型）、`AGENTS.md`（查询、回答和写回的规则）和 `_templates/`。卡片之间用 `source_refs` 等字段串成来源链路，跨库用 `related:` 关联，反向链接由索引自动计算。

### DSH 模式

- **知识库模式**：整理和扩充知识库。查重、按模板写卡片、跨库关联、校验，每一步都有对应的工具和 skill。
- **实验模式**：孩子的 AI 实验室。查知识库和 [sci-playground](https://handsondad.github.io/sci-playground/) 科学馆，必要时上网收集优质实验，经过安全检查后为孩子生成可以动手做的互动实验页，也可以把好的实验以草稿形式写回趣味科学实验库。

安装与使用见 [dsh/README.md](dsh/README.md)，扩充内容和开发新能力见 [AGENTS.md](AGENTS.md)。

## 项目目标

通过游戏化的学习方式和系统化的知识体系，促进儿童全面发展，包括认知、语言、运动、社交和科学探究能力，同时激发他们对科技的兴趣和探索精神。

## 技术特点

- 结构化知识库：Markdown 卡片加 YAML frontmatter，统一的编号、状态和引用规则，`npm run kb:check` 校验
- 知识互联：来源链路、跨库关联和自动反向链接，一个问题可以顺着关联查到游戏、心理、语言和科学多个库
- DSH 集成：知识库工具、按库的 skill 和多个模式，所有模式共享同一个知识库
- 年龄和领域分类：按照儿童发展规律组织内容，检索时可以按年龄、时长和安全等级筛选
- 多领域覆盖：涵盖游戏、语言、心理、科学、AI 等多个儿童发展领域
