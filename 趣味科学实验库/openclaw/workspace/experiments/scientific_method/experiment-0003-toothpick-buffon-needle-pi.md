# 实验简介

这个实验把经典的蒲丰投针问题改成家庭或课堂可完成的版本：在画有等距平行线的纸上随机投掷牙签或大头针，统计相交次数，再用统计比例估算 `π`。它既是一个数学味很强的科学活动，也是一张很好的“随机性与大数定律”实验卡。

## 准备材料

- 长度尽量一致的牙签或大头针若干
- 白纸
- 直尺
- 笔
- 记录用纸或计算器

## 操作步骤

1. 先测量牙签长度，并在白纸上画多条互相平行的直线，让相邻两条线的间距尽量等于牙签长度。
2. 把纸平铺在桌面或地面上，确保表面平整。
3. 从固定高度随机投掷牙签，每次投后记录这根牙签是否与任一条线相交；超出区域的重投。
4. 重复很多次，最好累计至少 200 次以上，记录总投掷次数 `N` 和相交次数 `M`。
5. 当线距等于牙签长度时，可用近似公式 `π ≈ 2N / M` 来估算圆周率，并比较结果与 `3.14` 的差距。

## 预期观察结果

- 单批次结果会有波动，不会每次都非常接近 `3.14`。
- 随着投掷次数增加，估计值通常会逐渐稳定一些。
- 如果投掷不够随机，或者线距、针长不够准确，结果偏差会明显增大。

## 科学原理

- 这个实验的底层是几何概率问题。
- 当针长等于线距时，针与线相交的理论概率与 `π` 有固定关系。
- 真实实验中无法直接看到理论概率，但可以通过大量重复实验，用“相交次数 / 总次数”去估计它。
- 样本量足够大时，统计比例会更接近理论概率，这体现了大数定律。

## 变量与对照

- 关键条件包括针长、线距、投掷方式和样本量。
- 如果要严格使用 `π ≈ 2N / M`，应尽量保证线距等于针长。
- 若要比较实验效果，可以只改变投掷次数，观察估计值稳定性如何变化。

## 安全提醒

- 如果使用大头针，需注意尖端扎伤风险。
- 做完后应及时回收，避免遗落在地面；可用磁铁辅助回收金属针。

## 延展变体

- 简化版：用牙签代替大头针，降低风险。
- 进阶版：分批记录 50 次、100 次、200 次、400 次时的估计值变化。
- 延展问题：如果线距不等于针长，公式应如何调整。
