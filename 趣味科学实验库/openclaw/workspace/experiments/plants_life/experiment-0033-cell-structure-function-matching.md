# 实验简介

通过卡片配对方式，把常见细胞结构与其主要功能建立对应关系。目标是形成结构-功能思维，而非术语背诵。

## 操作步骤

1. 准备两组卡片：结构名称卡与功能描述卡。
2. 先让学习者独立配对，再小组讨论差异。
3. 对每一组配对要求给出一句解释。
4. 最后总结哪些结构最容易混淆。

## 科学原理

- 生物系统理解常依赖结构与功能对应。
- 解释性配对比机械记忆更能支持后续迁移。
