# 专题说明

这张任务卡用于训练“先预测、再验证、再解释偏差”的变量控制能力。

## 推荐顺序

1. 先在 `collection-0011` 选择一个可对比实验
2. 固定除 1 个变量外的其余条件
3. 记录两组及以上结果并比较差异
4. 回到 `collection-0006` 对照科学方法，复盘偏差来源

## 包含卡片

- `collection-0011`: 物理互动学习入口
- `collection-0006`: 全局路线地图与方法入口
- `experiment-0029`: 摆长比较
- `experiment-0004`: 坡道小车对比

## 使用建议

- 每轮只改 1 个变量，否则难以解释结果
- 输出记录建议：实验对象 / 控制变量 / 干预变量 / 结果对比 / 偏差原因 / 下轮优化

## 检索提示

- 控制变量训练任务，强调预测验证和偏差解释，适合方法能力强化。
