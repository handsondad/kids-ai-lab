# 专题说明

这张合集是 science_kb 的单页控制台入口，目标是减少选择成本：先判断你的场景，再跳入一条主路线，不需要先浏览全部卡片。

## 场景分区导航

### 场景 A：家庭当天可做（低材料、短时完成）

- 首选：`collection-0007`
- 适用：今天就要做 1 到 2 个高成功率实验
- 下一步：完成后回本卡，转到 `collection-0010` 或 `collection-0011`

### 场景 B：课堂备课与教学组织（结构化可复用）

- 首选：`collection-0012`
- 配套：`collection-0008`
- 适用：需要按学习阶段组织教学顺序、补齐课程主干

### 场景 C：长期观察项目（连续记录、周度复盘）

- 首选：`collection-0010`
- 扩展：`collection-0013`
- 进阶：`collection-0014`
- 适用：想做自然笔记、植物与昆虫观察、生态变化追踪

### 场景 D：概念补强与方法迁移（学会举一反三）

- 首选：`collection-0006`
- 扩展：`collection-0011`
- 适用：需要先有全局地图，再进入模型、变量控制和推理训练

## 常见任务直达索引

### 任务 1：今天只有 20 分钟，做一个高成功率活动

- 先开：`collection-0007`
- 建议优先卡片：`experiment-0001`、`experiment-0009`、`experiment-0013`

### 任务 2：给孩子做一周自然观察计划

- 先开：`collection-0010`
- 第二步：转到 `collection-0013`
- 记录重点：时间、地点、对象、变化线索

### 任务 3：准备一节 40 分钟科学课

- 先开：`collection-0012`
- 配套：`collection-0008`
- 备课节奏：引入现象 -> 操作活动 -> 变量讨论 -> 结论回收

### 任务 4：想训练“控制变量 + 推理”能力

- 先开：`collection-0011`
- 回补：`collection-0006`
- 目标：先预测，再验证，再解释偏差

### 任务 5：已有基础，想进阶到生物机制层

- 先开：`collection-0014`
- 进入前建议：先完成 `collection-0010` 或 `collection-0012` 中任意一条主线

## 60 秒选路规则

1. 先定场景：当天做、课堂用、长期观察、概念补强
2. 每次只开一条主线，最多并行一条扩展线
3. 完成一个回合后再回本卡换路线

## 推荐顺序

1. 新用户先用“场景分区导航”选一条主线
2. 仍不确定时先读 `collection-0006` 建立全局地图
3. 主线完成后，从专项路线中补一条：`collection-0010`/`collection-0011`/`collection-0012`
4. 需要机制层深化时进入 `collection-0014`

## 使用建议

- 本卡用于选路，不用于细读知识点；细读请进入子合集
- 每次只选一条主路线执行，避免并行开太多线导致中断
- 每完成一条路线后回到本卡，基于新目标选择下一条
