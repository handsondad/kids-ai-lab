# 专题说明

这张任务卡用于连续 7 天的自然观察，重点是形成稳定记录并识别至少 1 条变化趋势。

## 推荐顺序

1. 在 `collection-0010` 选定观察对象与地点
2. 使用 `experiment-0027` 建立每日记录框架
3. 按 `collection-0013` 补充植物或昆虫维度（可用 `experiment-0031` 或 `experiment-0032`）
4. 第 7 天总结“最明显变化 + 可能原因”

## 包含卡片

- `collection-0010`: 观察自然起步入口
- `collection-0013`: 植物与昆虫观察入口
- `experiment-0027`: 定点自然笔记
- `experiment-0031`: 树与叶现场特征记录
- `experiment-0032`: 昆虫微行为观察

## 使用建议

- 每天固定同一时段观察，减少时间差干扰
- 输出记录建议：日期 / 时间 / 地点 / 对象 / 变化线索 / 天气 / 推测原因
