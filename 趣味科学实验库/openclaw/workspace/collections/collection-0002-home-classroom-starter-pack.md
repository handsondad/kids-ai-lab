# 专题说明

这个合集面向家庭和课堂的入门使用场景，目标是先用一批低材料、高可观察性的实验，把最常见的科学高频主题搭起来。它不是按学科教条排序，而是按“看得见现象、讲得清变量、材料拿得到”来组织。

## 推荐顺序

1. 先从 `topic-0004` 和 `experiment-0004` 理解力、推拉与运动
2. 再用 `topic-0005`、`experiment-0005` 和 `experiment-0001` 进入空气阻力
3. 用 `topic-0006` 与 `experiment-0006` 讲浮沉与密度
4. 用 `topic-0007` 与 `experiment-0007` 连接蒸发和水循环
5. 用 `topic-0008` 与 `experiment-0008` 做长期生长观察
6. 用 `topic-0009` 与 `experiment-0009` 做光和影子的高反馈实验

## 包含卡片

- `topic-0004`: 力和运动的基础入口
- `topic-0005`: 解释为什么有些东西会掉得更慢
- `topic-0006`: 把浮沉从“猜结果”变成“讲原理”
- `topic-0007`: 连接日常水变少现象与地球上的水循环
- `topic-0008`: 把生物主题做成可持续观察项目
- `topic-0009`: 用影子把抽象光学变成直观变化
- `experiment-0004` 到 `experiment-0009`: 覆盖运动、空气、水、植物和光影的低材料实验入口

## 使用建议

- 一次先选一个主题配一张实验卡，不要把它们做成一口气连上的课程
- 每做完一张实验卡，最好都补一句“我们这次改了什么，保持了什么不变”
- 如果是课堂场景，可优先选择记录负担较低、成功率更高的项目起步
