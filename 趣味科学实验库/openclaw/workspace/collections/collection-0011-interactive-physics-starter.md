# 专题说明

这张合集把“物理互动资源”真正沉淀成了 science_kb 能长期复用的路线。重点不是把外部网站列一遍，而是把那些网站共同强调的方法写清楚：先理解解释，再做可视化比较，再做现实活动，再回头检查变量和预测。

## 推荐顺序

1. 先从 `topic-0004` 看力和运动，建立最基础的变化视角
2. 再用 `experiment-0004`、`experiment-0005` 和 `experiment-0015` 练习比较和变量控制
3. 用 `topic-0013` 与 `experiment-0013` 体验“看不见的过程也能通过模型看清”
4. 接着看 `topic-0030`，明确模型、模拟和现实实验之间是什么关系
5. 最后做 `experiment-0029`，把方法层真正用到一个新主题上

## 包含卡片

- `topic-0004`: 力、推拉与运动
- `topic-0005`: 空气阻力
- `topic-0013`: 声音与振动
- `topic-0015`: 摩擦与表面
- `topic-0030`: 物理中的模型、模拟与变量控制
- `experiment-0004`: 小车坡道运动对比实验
- `experiment-0005`: 简易降落伞空气阻力测试
- `experiment-0013`: 橡皮筋振动发声实验
- `experiment-0015`: 不同表面摩擦对比实验
- `experiment-0029`: 简易摆长与摆动节奏比较

## 使用建议

- 这套内容更适合小学高段到中学入门，重点放在比较、预测和复盘
- 如果配合外部互动资源使用，最好始终回到一个问题：这次我到底只改了哪个条件

## 检索提示

- 物理互动学习，模型与实验，变量控制，力和运动入门，摆长活动。
