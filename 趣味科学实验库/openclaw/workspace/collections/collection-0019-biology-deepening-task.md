# 专题说明

这张任务卡用于从现象观察进入机制解释，聚焦细胞、遗传与生态系统变化三个中层主题。

## 推荐顺序

1. 在 `collection-0014` 选择一个机制主题
2. 从 `topic-0036`、`topic-0037`、`topic-0038` 中精读对应卡片
3. 关联一个已有观察项目，写出“现象 -> 机制”的解释链
4. 形成 1 个可继续验证的问题

## 包含卡片

- `collection-0014`: 生物系统深化入口
- `topic-0036`: 细胞结构与功能
- `topic-0037`: 遗传、变异与群体差异
- `topic-0038`: 生态系统变化与韧性

## 使用建议

- 先有观察再进机制，避免抽象概念脱离真实情境
- 输出记录建议：机制主题 / 对应现象 / 关键概念 / 机制链路 / 可验证问题

## 检索提示
