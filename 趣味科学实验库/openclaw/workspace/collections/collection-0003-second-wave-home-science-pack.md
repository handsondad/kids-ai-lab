# 专题说明

这个合集承接第一批入门内容，继续把知识库扩到材料变化、电磁、声音和天气观察几个高频入口。它适合已经做过几次简单实验、想继续扩大学科覆盖的人使用。

## 推荐顺序

1. 先从 `topic-0010` 与 `experiment-0010` 理解溶解和比较观察
2. 再看 `topic-0011` 与 `experiment-0011`，做磁铁材料分类
3. 然后用 `topic-0012` 与 `experiment-0012` 进入最小电路概念
4. 用 `topic-0013` 与 `experiment-0013` 理解声音来自振动
5. 最后用 `topic-0014` 与 `experiment-0014` 把单次实验扩展到连续天气观察

## 包含卡片

- `topic-0010` 到 `topic-0014`: 覆盖溶解、磁铁、电路、声音和天气观察五个常用入口
- `experiment-0010` 到 `experiment-0014`: 对应五张低材料、高可观察性的实验或观察活动卡

## 使用建议

- 这批内容里，电路和磁铁更适合近距离看护场景，天气观察更适合长期记录场景
- 做完实验后，优先回到“这次看到了什么、改了什么、哪些条件没变”这三个问题

## 检索提示

- 第二批家庭科学实验，溶解、磁铁、电路、声音、天气观察，低材料入门包。
