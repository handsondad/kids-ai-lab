# 核心观点

- 第二批实验要继续保持低材料和高可观察性，但可以比第一批更强调“看不见的过程如何通过结果显现出来”。
- 溶解、电流和振动都不是肉眼直接看到的整体过程，因此实验卡需要把观察点写得更明确。
- 磁铁和天气观察则适合做分类、记录和模式比较，有利于把知识库从单次实验扩展到连续观察。
- 入门电路实验要特别重视安全和器材边界，避免把“能亮”误导成所有导线和电池玩法都安全。
- 这批实验更适合同时训练“预测、记录、解释”三步，而不是只做现象演示。

## 可拆出的卡片

- 盐和糖的溶解快慢对比
- 磁铁吸引材料分类实验
- 纽扣电池点亮 LED 简易电路

- 一周天气观测记录实验
