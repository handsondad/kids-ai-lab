# 核心观点

- 元素可以看作构成许多材料的更底层单位。
- 周期表的重要性不在于死背顺序，而在于它把元素放进一个有规律的排列框架中。
- 学习材料时，如果只停留在日常名字，很容易碎片化；加入元素和周期性的视角后，更容易形成结构化理解。
