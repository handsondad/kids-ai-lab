# 核心观点

- 蒲丰投针实验展示了如何用随机实验去估计一个数学常数，而不是直接依靠几何测量。
- 当针长与平行线间距相等时，针与线相交的概率可以化简成与 `π` 相关的表达式。
- 实验中真正可观测的是“是否相交”，真正可统计的是“相交次数占总次数的比例”。
- 单次投掷结果不可预测，但大量重复后，统计比例会逐渐靠近理论概率，这体现了大数定律。
- 这类思路和现代蒙特卡洛方法相通，即用大量随机样本去逼近复杂问题的答案。
