# 核心观点

- 第三批实验需要把“瞬间现象”与“持续过程”两类活动结合起来，避免知识库只剩下短平快演示。
- 摩擦和热传递适合做明确对比测试，水循环、凝结和生态观察更适合拉长时间线做记录。
- 这批实验更依赖固定观察方法，否则很难比较前后差异。
- 连续观察类活动不应因为没有剧烈变化就被看作弱实验，它们在科学训练中同样重要。
- 记录模板、观察点和讨论问题，在这批实验卡里要写得比第一批更明确。

## 可拆出的卡片

- 不同表面的摩擦对比
- 冰块融化快慢对比
- 袋中迷你水循环
- 冷杯凝结观察
- 校园或小区微栖息地观察

## 学习者会怎么问

- 怎么让孩子看见摩擦不是抽象词
- 热传递有什么适合家里做的实验
- 水循环能不能做成一个持续观察项目
- 杯子外壁为什么会起水珠
- 生态观察记录什么才有价值

## 备注

- 这张笔记用于第三批实验卡起步，后续可继续接真实来源
