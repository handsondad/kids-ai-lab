# 核心观点

- 第四批实验比前三批更强调“现象背后有类别和规则”，而不只是直接做出一个好玩的结果。
- 酸碱和热胀冷缩适合做条件变化测试，简单机械适合做省力比较，云雨与分解者更适合做模型观察和连续观察。
- 这批实验需要更明确地区分“示意模型”和“真实自然过程”，避免把模型当成完全等价的现实。
- 安全边界在这批内容里尤其重要，尤其是酸碱和热相关内容仍应停留在低风险家用材料级别。
- 记录和解释在这批卡里同样重要，不能只停留在“看到了颜色变化”或“球胀起来了”。

## 可拆出的卡片

- 红甘蓝或家用材料酸碱指示实验
- 瓶口气球热胀冷缩实验
- 尺子杠杆省力实验
- 瓶中云或云雨模型观察
- 落叶/果皮分解观察

## 学习者会怎么问

- 酸碱实验怎么做得安全
- 热胀冷缩有什么明显现象
- 什么样的实验最能讲杠杆
- 云雨模型怎么做
- 分解者怎么讲得不空泛
