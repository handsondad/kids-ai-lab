# 核心观点

- 第二批高频主题适合继续扩展知识库的横向覆盖，让家庭和课堂不只停留在力、空气和植物，也进入材料变化、电磁、声音和天气观察。
- 这些主题依然适合采用“主题卡 + 实验卡”的双线结构，因为它们既需要概念解释，也非常适合低材料操作。
- 溶解、磁铁、电路、声音和天气观察都很适合做变量对照与长期记录。
- 这批主题里既有强操作型内容，也有偏观察型内容，有助于丰富知识库的问题类型。
- 对初学者来说，这批主题的关键不是一次讲很深，而是先抓住最稳定的观察规则和可重复现象。

## 可拆出的卡片

- 溶解与溶解快慢
- 磁铁与磁性材料
- 简单电路与闭合回路
- 声音与振动
- 天气观测与记录

## 学习者会怎么问

- 盐为什么放进水里就不见了
- 磁铁为什么有的东西吸得住有的吸不住
- 灯泡为什么一定要接成一个圈才会亮
- 声音到底是怎么产生的
- 天气观察到底在看什么
