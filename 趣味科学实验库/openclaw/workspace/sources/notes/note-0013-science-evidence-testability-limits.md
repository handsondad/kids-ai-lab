# 核心观点

- 科学不只是事实清单，而是一种组织证据、提出解释、持续修正的知识生产活动。
- 科学解释需要指向自然世界中的现象，并且原则上能被检验或反驳。
- 证据不是“我觉得像”，而是可共享、可记录、可讨论的观察结果。
- 科学共同体的重要性在于重复检验、互相质疑和公开修正，而不是靠某个权威一次定论。
- 科学有适用边界，它能回答“自然界如何运作”，但不直接替代伦理、审美和价值判断。
