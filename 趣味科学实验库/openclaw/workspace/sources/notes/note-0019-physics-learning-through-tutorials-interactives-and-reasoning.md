# 核心观点

- 物理学习往往需要在几种活动之间来回切换：先读解释，再做交互，再做推理，再回到现实活动。
- 同一个概念如果只做一次现象演示，理解很容易停留在表面。
- 教师生成的教程和互动资源，特别适合帮助初学者反复比较自己的误解和实际规律之间的差距。
- 对 science_kb 来说，更重要的不是保存整套课程，而是把这种“多次往返”的学习结构沉淀成合集路线。
