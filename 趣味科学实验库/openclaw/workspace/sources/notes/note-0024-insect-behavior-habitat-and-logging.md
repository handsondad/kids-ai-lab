# 核心观点

- 昆虫观察的关键不只是识别外形，还包括移动方式、取食、停留位置和活动时段。
- 同一种昆虫在不同温度、湿度和时间段中的出现概率可能不同。
- 记录行为线索和微环境，可以让昆虫观察从“看到一只”升级为“比较模式”。
