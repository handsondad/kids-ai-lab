# 核心观点

- 物理模型和交互模拟的价值，在于把多个变量拆开，让学习者一次只盯住一个变化。
- 好的入门学习不只是“看见结果”，还包括先预测、再修改变量、再比较结果是否符合预测。
- 模型不是现实的复制品，而是为了突出某个关键关系而做的简化。
- 当学习者能在模型里看清关系后，再回到真实材料活动中，更容易理解为什么现实结果会有误差和波动。
