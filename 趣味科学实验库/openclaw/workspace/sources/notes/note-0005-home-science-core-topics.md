# 核心观点

- 家庭和课堂最常用的科学主题，通常不是抽象公式，而是能直接和现象连接起来的高频概念，比如力、空气阻力、浮沉、蒸发、发芽和影子。
- 这些主题之所以适合作为知识库早期种子，是因为它们材料低门槛、观察明显、可变变量清楚，适合持续复用。
- 每个高频主题最好同时配一张概念卡和至少一张实验卡，这样知识库既能回答“是什么”，也能回答“怎么验证”。
- 高质量的入门解释不追求一步讲完全部机制，而应先抓住最稳定、最容易观察的因果链。
- 对儿童和初学者来说，比较实验往往比单次演示更有价值，因为它更容易看出变量与结果的关系。

## 可拆出的卡片

- 力、推拉与运动
- 空气阻力
- 浮沉与密度
- 蒸发
- 种子发芽
- 光与影子

## 学习者会怎么问

- 什么是力，怎么让孩子看见力的作用
- 为什么有的东西会浮、有的会沉
- 水为什么会自己变少
- 种子发芽到底需要什么条件
- 为什么影子会变长变短
