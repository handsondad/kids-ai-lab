# 核心观点

- 观鸟记录的科学价值，不只在于“看见了哪种鸟”，还在于它发生在什么时间、什么地点、数量大致多少、是否有图片或其他证据。
- 平台将记录分成不同方式，例如定点记录、随手记录和图片记录，这说明观察任务的场景和证据形式会影响记录方法。
- 查询和统计功能让观察者可以把自己的见闻放到更大的空间和时间背景中比较。
- 连续记录身边常见鸟种，比追逐稀有记录，更适合儿童和家庭形成稳定观察习惯。
