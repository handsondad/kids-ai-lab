# 核心观点

- 第四批主题进一步把知识库从常见现象扩展到更典型的课程入口，包括酸碱、热胀冷缩、简单机械、云雨类型和食物链/分解者。
- 这批主题有一个共同点：都适合从生活经验切入，再逐步上升到更系统的解释。
- 对初学者来说，这些概念最容易卡住的地方，不是现象看不到，而是容易把多个过程混在一起，所以主题卡需要先把边界讲清楚。
- 这批内容同时适合课堂和家庭，因为既有短实验，也有观察和讨论型活动。
- 它们也很适合后续接入真实文章来源，例如科普文章、课堂笔记或实验手册。

## 可拆出的卡片

- 酸与碱的初步区分
- 热胀冷缩
- 杠杆与简单机械
- 云与降水类型线索
- 食物链与分解者

## 学习者会怎么问

- 酸和碱到底怎么区分
- 为什么热的时候会膨胀
- 为什么用长尺子撬东西更省力
- 云为什么会变成雨
- 食物链最后的东西都去哪了
