# 核心观点

从 How to Smile (https://www.howtosmile.org/) 网站收集了多个适合儿童的趣味科学实验，这些实验使用常见家庭材料，安全易操作，非常适合亲子共同探索科学世界。

## 主要资源特点

- 收录超过4000个精选STEM活动
- 可按年龄、材料成本、学习时间筛选
- 来源包括科学博物馆、公共电视台、大学等教育机构
- 涵盖主题：能源、气候、生命科学、海洋、天文学、烹饪等

## 收集的实验列表

### 1. 跳舞的葡萄干 (Dancing Raisins)
- **原理**：密度与气泡
- **材料**：碳酸饮料、葡萄干
- **适合年龄**：2-4岁
- **对应实验卡**：experiment-0070

### 2. 自制熔岩灯 (Lava Lamp)
- **原理**：密度差异
- **材料**：油、水、食用色素、泡腾片
- **适合年龄**：4-12岁
- **对应实验卡**：experiment-0071

### 3. 棉花糖弹射器 (Marshmallow Catapult)
- **原理**：杠杆原理与能量转换
- **材料**：冰棒棍、夹子、瓶盖、棉花糖
- **适合年龄**：6-14岁
- **对应实验卡**：experiment-0072
