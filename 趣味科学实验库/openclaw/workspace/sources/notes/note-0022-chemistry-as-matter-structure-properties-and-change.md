# 核心观点

- 化学可以看作研究物质是什么、怎样组成、有哪些性质、会发生哪些变化的一门学科。
- 入门学习不必一开始就钻进大量符号，而应先学会观察材料、比较性质和区分变化类型。
- 当孩子开始能区分组成、性质、结构和变化这几个问题时，后续的元素、分子、反应才更容易接上。
