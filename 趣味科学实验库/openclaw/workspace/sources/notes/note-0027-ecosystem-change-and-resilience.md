# 核心观点

- 生态系统会随季节、气候、人类活动和物种变化而动态调整。
- 生态韧性是系统在扰动后维持或恢复功能的能力。
- 入门学习可从身边小尺度环境变化观察开始，不必一开始上升到全球尺度。
