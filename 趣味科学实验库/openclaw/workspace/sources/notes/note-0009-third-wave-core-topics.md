# 核心观点

- 第三批主题更强调“一个现象背后不只是一条单独知识点，而是一整组过程在一起发生”。
- 摩擦、热传递、水循环、凝结和生态观察都很适合帮助学习者从单次实验走向系统理解。
- 这批主题里，比较和长期观察同样重要，很多结论不是靠一次操作，而是靠连续记录和条件变化来建立。
- 对初学者来说，系统性主题仍然要先落到可观察现象，不宜直接堆抽象定义。
- 这批主题适合把前面已经建立的“变量、记录、证据”方法继续复用。

## 可拆出的卡片

- 摩擦与表面
- 热传递与冷热变化
- 水循环
- 凝结与云雨形成线索
- 栖息地与生态观察

## 学习者会怎么问

- 为什么有些表面更滑有些更涩
- 冰为什么在不同条件下融化速度不一样
- 水循环到底怎么和日常现象连起来
- 杯子外面的水珠是从哪里来的
- 生态观察到底观察什么
